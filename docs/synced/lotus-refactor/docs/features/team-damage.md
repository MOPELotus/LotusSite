队伍伤害分为两个页面维护：

- [队伍伤害-原神](https://github.com/MOPELotus/Lotus-ReFactor/blob/main/docs/features/team-damage-genshin.md)
- [队伍伤害-星铁](https://github.com/MOPELotus/Lotus-ReFactor/blob/main/docs/features/team-damage-starrail.md)

两个页面都支持 profile 后缀。没有后缀时使用 profile 1；带后缀时使用指定 profile 的登录态和 UID。
