# 实用工具与娱乐

## 点歌与天气

小飞插件提供点歌、天气和少量账户辅助功能：

| 命令 | 用途 |
| --- | --- |
| `#点歌 歌曲名` | 搜索并返回歌曲候选。 |
| `#多选点歌 歌曲名`、`#QQ点歌 歌曲名`、`#网易点歌 歌曲名` | 使用多选列表或指定平台搜索。 |
| `#歌词 歌曲名` | 查询歌词。 |
| `#语音 歌曲名`、`#高清语音 歌曲名` | 尝试获取语音形式的歌曲。 |
| `#天气 城市` | 查询天气。 |
| `#原神注册时间 UID` | 查询游戏账号注册时间（如果上游服务可用）。 |

也可发送 `#小飞帮助` 查看部署当前版本的完整菜单。点歌音源及可播放质量受平台、地区和账号权益影响。

## 表情、抽卡与群内小游戏

- Earth-K（土块）插件的常见指令：`#你说我猜`、`#画我猜`、`#角色动画列表`、`#猜语音`、`#猜原神`、`#练习记忆力`、`#点视频`、`#点漫画`、`#点小说`、`#了解刻晴`、`#原史刻晴`、`#钢琴12315`。发送 `#土块帮助` 查看完整列表。
- `#表情包列表` 查看表情功能菜单；可按机器人提示提交关键词或图片。
- 抽卡模拟和自定义卡池功能请先看 `#抽卡帮助` 或对应游戏帮助。模拟抽卡不改变真实游戏账户。
- 抽卡期望计算是跨游戏通用指令，因此使用 `#`：例如 `#期望计算 原神 角色 3个`、`#期望分布 星铁 角色 1个 预算150抽`。插件支持范围以 `#期望计算帮助` 为准。

## 定时指令

如果机器人已开放 auto-plugin 定时任务，可以这样安排一次延迟操作：

```text
#定时指令 -s=300 -t="#更新面板"
```

这里 `-s` 是延迟秒数，`-t` 是要执行的机器人指令。重复任务可用 cron 参数 `-c`，示例：

```text
#定时指令 -c="0 0 8 * * ?" -t="#体力"
```

任务依赖机器人持续在线，机器人重启或停止时可能无法按预期执行。请勿安排群发、管理或会访问账号敏感数据的命令；主人可通过 `#任务表` 管理任务。

## 高权限与危险功能

**天如插件可能带有模拟身份、执行脚本或服务器命令等维护功能。** 这些功能不是普通用户娱乐指令；除非你是服务器所有者且已审阅插件代码，否则不要尝试执行 `#执行sh`、`#执行js`、`#我是` 等命令，也不要照抄他人发来的脚本。

公告发布、日志转发、群管处罚、插件更新、定时任务和批量消息通常仅对机器人主人或群管理员开放。普通用户不要尝试猜测权限口令。
