# Yunzai 机器人使用指南

本指南面向在群聊中使用机器人的用户，介绍当前已安装插件的常见用法。机器人不提供私聊交互。不同群可能启用不同功能；遇到“没有权限”“功能未开启”或指令无法识别时，请联系荷花。

## 从这里开始

1. 在群内先发送 `#帮助` 查看机器人返回的菜单；部分插件有单独帮助命令。
2. 按帮助中的示例发送指令：原神或通用指令使用 `#`，星穹铁道使用 `*`，绝区零使用 `%`。荷花插件的设备绑定命令由插件接管，例外情况见对应章节。
3. 查询自己的游戏账户数据时，先阅读[指令写法与权限](/yunzai/commands)中的账号安全说明。
4. 找不到功能时，查看[常见问题](/yunzai/faq)，或使用下方对应游戏/插件的帮助命令。
