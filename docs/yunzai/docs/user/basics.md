# 基础功能

[返回用户指南概览](/yunzai/docs/user/index)

在聊天窗口直接发送指令即可使用，普通用户无需打开终端或管理面板。首次使用可按以下步骤上手：

1. 在 [常用功能跳转表](/yunzai/docs/user/commands) 查找目标功能的指令写法。
2. 公开图鉴与攻略可直接发送指令查询；需要使用个人战绩、签到或同步数据等功能时，先前往 [账号绑定与管理](/yunzai/docs/user/accounts) 完成绑定或登录。

## 游戏前缀与命令路由

机器人通过指令开头的前缀判断目标游戏（路由规则见 [lib/command-prefix.ts](https://github.com/MOPELotus/Lotus-Yunzai/blob/main/lib/command-prefix.ts)）：

| 游戏 | 规范前缀 | 兼容前缀 | 已确认命令示例 |
| :--- | :--- | :--- | :--- |
| 原神 | `#`（或 `#原神`） | — | `#面板`、`#胡桃图鉴` |
| 崩坏：星穹铁道 | `#星铁` | `*`、部分命令支持 `sr` | `#星铁面板`、`#星铁丹恒图鉴` |
| 绝区零 | `#绝区零` | `%`、部分命令支持 `zzz` | `#绝区零面板`、`#绝区零安比图鉴` |

前缀仅用于选择目标游戏，不代表所有命令都能机械套用到三款游戏上。各游戏实际支持的指令以 [常用功能跳转表](/yunzai/docs/user/commands) 及对应功能页为准。

## 公开资料与个人数据

- 公开资料查询：如 `#胡桃图鉴`、`#星铁丹恒图鉴`、`#绝区零安比图鉴` 及各类攻略查询（见 [攻略查询](/yunzai/docs/user/guides)），读取公开游戏资料，无需扫码登录或绑定账号。
- 个人数据与操作：如每日签到、兑换码使用、个人游戏战绩查询、在线拉取抽卡记录等，涉及个人隐私与账号凭据，需按 [账号绑定与管理](/yunzai/docs/user/accounts) 完成登录或凭据绑定（涉及明文凭据录入与高敏感操作时须在本人好友私聊中进行）。

## UID、登录凭据、设备信息、档案与缓存

- 角色 UID：游戏内的数字编号。登录通行证后，机器人将该通行证返回的角色目录保存到对应账号档案中；角色列表（`#uid`、`#角色列表`）仅读取单个档案的已迁入历史目录，登录失效时仍可能查看该目录，但执行切角（`#uid<序号>`、`#切换角色 <序号|UID>`，序号 `1..99`）必须校验当前登录状态与角色归属，且切角只在同一档案内生效，不会混用其他档案或修改默认档案。旧的独立 UID 绑定、设置/切换 UID、签名验证及公开 UID 登记/列表/切换入口均已停用，不再生成签名口令；旧归档予以保留，但不作为默认绑定、导出授权或旧面板恢复依据。如需临时匿名读取公开展柜角色数，可使用 `#查询公开UID <完整UID>`，不构成账号绑定。本地缓存与面板导出的权限及范围分别见 [角色面板查询](/yunzai/docs/user/panels) 与 [抽卡记录与分析](/yunzai/docs/user/gacha)。
- 完整登录账号：通过登录流程获得的账号凭据（如 Cookie / Stoken 等），用于每日签到、兑换码、完整战绩或在线抽卡记录拉取等需要官方身份授权的功能，详见 [账号绑定与管理](/yunzai/docs/user/accounts)。
- 设备信息：与登录账号和接口请求配套保存的设备标识参数，独立于角色 UID 与账号档案编号，按账号管理流程关联。
- 账号档案编号：用于在同一个聊天账号下区分多套登录凭据或配置（支持档案 `1..255`）。未填写档号时，账号管理类指令（如 `#扫码登录`、`#配置`）仍默认操作档案 1；游戏指令则按当前设置自动路由到对应游戏的默认档案（通过 `#切换档案<档号>`、`*切换档案<档号>`、`%切换档案<档号>` 按游戏分别设置，要求目标档案已登录且拥有该游戏角色，切换后保持该档案原有选定角色；`#当前档案` 与 `#档案列表` 仅作只读查询），具体路由逻辑见 [packages/account/command-profile.ts](https://github.com/MOPELotus/Lotus-Yunzai/blob/main/packages/account/command-profile.ts)。
- 面板缓存与本地记录：查询 `#面板`、`#星铁面板`、`#绝区零面板` 或读取已保存数据时，优先使用本地缓存或本地记录，不会每次都实时请求游戏服务器，刷新受游戏接口与限频约束。

## 群聊、私聊与权限限制

- 群聊与私聊的隐私边界：提交 Cookie / 云游戏 Token 明文、绝区零获取抽卡链接、面板文件导入导出等高敏感操作仍仅限与机器人的本人好友私聊进行。扫码登录、设备绑定/解绑、本人角色列表等入口支持群聊使用，但不建议在群聊直接发送个人账号信息；群聊中由机器人发出的个人类回复默认在 120 秒内自动撤回（若功能本身设定了更短时限则保留更短值），用户发送设备信息原文时机器人会尝试立即撤回，无群管理权限时将提示用户自行撤回。
- 权限与开关由主人配置：主人可针对群聊、私聊或不同功能设置权限和开关，因此并非所有功能都对全部用户默认开放，每日签到也并非默认对所有用户开启。
- 同文去重与限频：即使主人关闭了全局群聊冷却（`groupCD`）或个人冷却（`singleCD`），同文去重及各功能自身的限频机制仍可能存在，短时间内重复发送相同指令会被忽略或提示冷却。

## 参数、引用与艾特写法

- 前缀与指令组合：游戏前缀放在指令最前方，中间不加空格，例如 `#面板`、`#星铁丹恒图鉴`、`#绝区零面板`。
- 数字与档案参数：指令中数字的含义取决于具体命令，不能一概而论。例如 `#uid2` 中的 `2` 是当前角色列表中的第 2 个角色序号，指定档案需要写成 `#uid 档案2`；而在 `#扫码登录2` 中，`2` 表示账号档案 2。
- 引用消息与艾特（@）：部分群聊互动或管理类指令支持通过引用（回复）目标消息或 `@` 群成员指定操作对象，具体支持情况见 [群聊功能与互动](/yunzai/docs/user/group)。
