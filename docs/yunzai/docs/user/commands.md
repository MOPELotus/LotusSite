# 常用功能跳转表

[返回用户指南概览](/yunzai/docs/user/index)

本页按主题汇总各功能的规范命令示例、前置条件与对应专题页链接。如需了解完整参数、别名或详细操作流程，请点击各行右侧的专题链接。

## 命令前缀与档案说明

- 游戏前缀：原神默认使用 `#`；星穹铁道规范前缀为 `#星铁` 或 `*`；绝区零规范前缀为 `#绝区零` 或 `%`。
- 档案号与角色序号：账号管理与签到类命令末尾的数字（如 `#扫码登录2`）为账号档案编号（范围 `1..255`，未填默认 `1`）；`*UID2`、`*切换角色2` 中的数字为当前档案内的角色序号（范围 `1..99`），两者概念不同，请勿混淆。
- 默认档案：游戏查询命令与本人角色视图（如 `#UID`、`*切换角色2`）未显式指定档案号时，使用当前游戏各自保存的默认档案（未切换过时默认 `1`）；账号管理与签到类命令未带档案号时仍固定默认档案 `1`。绝区零如需同时指定技能与档案，请显式写出（如 `#绝区零安比伤害 技能 2`、`档案 2`）。

| 切换当前档案角色 | `*切换角色2` / `*UID2` | 支持群聊（120 秒撤回）与好友私聊；需对应档案已登录且归属本人；数字为当前档案内的角色序号（1..99，或指定完整 UID），只切当前游戏角色，不改变默认档案 | [账号绑定与管理](/yunzai/docs/user/accounts) |

| 绑定设备信息 | `#绑定设备2` | 支持群聊与本人好友私聊，需已登录对应档案；需在同一会话 120 秒内提交设备 JSON 或设备 ID/FP（群聊将立即尝试撤回设备原文，无权限时提示自行撤回，回复 120 秒撤回） | [账号绑定与管理](/yunzai/docs/user/accounts) |
