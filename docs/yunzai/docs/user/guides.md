## 一、公共三游图鉴

### 1. 通用图鉴与前缀规则

你可以使用 `#图鉴` 统一查询三款游戏的角色、武器/光锥/音擎、套装、邦布、敌人、七圣召唤卡牌或部分挑战资料，也可以直接使用各游戏专属前缀进行快捷查询：

- 原神：`#` 或 `#原神`
- 星铁：`*`、`#星铁`、`#崩铁`、`#星穹铁道`、`#崩坏星穹铁道`
- 绝区零：`%`、`％`、`#绝区零`、`#绝区`

| 功能 | 命令格式 | 示例 |
| :--- | :--- | :--- |
| 通用图鉴查询 | `#图鉴 [原神\|星铁\|绝区零] 名称或 ID` | `#图鉴 星铁 流萤` |
| 连写快捷查询 | `#图鉴<名称>` | `#图鉴胡桃` |
| 快捷图鉴 | `<前缀><名称>图鉴` 或 `<前缀><名称>` | `*黄泉图鉴`、`%星见雅` |
| 查看图鉴帮助 | `#图鉴帮助` | `#图鉴帮助` |
| 查看图鉴状态 | `#图鉴状态` | `#图鉴状态` |

### 2. 分类精确查找

当通用查询结果较多或名称存在重名时，建议使用分类指令缩小范围：

| 类别 | 命令格式 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| 角色 | `#角色图鉴 [原神\|星铁\|绝区零] 名称或 ID` | `#角色图鉴 绝区零 艾莲` | 返回匹配角色列表与 ID |
| 角色详情快捷 | `<前缀><角色名><关键词>` | `#胡桃命座`、`*流萤星魂` | 原神支持命座/天赋/写真；星铁支持星魂/行迹；绝区零支持影画/天赋（不支持写真/照片） |
| 武器 / 光锥 / 音擎 | `#武器图鉴 [游戏] 名称或 ID`<br>`#光锥图鉴 名称或 ID`<br>`#音擎图鉴 名称或 ID` | `#武器图鉴 护摩之杖`<br>`#光锥图鉴 镜中故我`<br>`#音擎图鉴 深海访客` | 光锥限星铁，音擎限绝区零 |
| 套装 | `#套装图鉴 [游戏] 名称或 ID`<br>`#圣遗物图鉴 名称或 ID`<br>`#遗器图鉴 名称或 ID`<br>`#驱动盘图鉴 名称或 ID` | `#圣遗物图鉴 绝缘之旗印`<br>`#遗器图鉴 死水深潜的先驱`<br>`#驱动盘图鉴 极地重金属` | 分别对应原神、星铁、绝区零 |
| 邦布 | `#邦布图鉴 名称或 ID` | `#邦布图鉴 鲨牙布` | 仅限绝区零 |
| 成就 | `#成就图鉴 [游戏] 成就名或 ID` | `#成就图鉴 原神 旅途的终点` | 支持按名称或 ID 查找 |
| 成就分类 | `#成就分类 [游戏] [分类名] [第N页]` | `#成就分类 星铁 第2页` | 每页显示 12 条，可翻页 |


## 二、公共挑战图鉴与个人战绩的区别

- 公共挑战图鉴：查询的是游戏内公共轮换关卡、敌人配置、环境 Buff 与时间安排，反映的是公共关卡本身，不涉及任何个人账号数据。
- 个人战绩：查询的是你自己账号的通关记录、星数、配队与练度（需先完成账号绑定，详见 [游戏战绩与数据查询](/yunzai/docs/user/records)）。

### 挑战图鉴命令

| 命令格式 | 示例 | 说明 |
| :--- | :--- | :--- |
| `#挑战图鉴 原神\|星铁\|绝区零 模式 [名称或记录 ID \| 本期 \| 上期 \| 下期 \| 第N页]` | `#挑战图鉴 星铁 混沌回忆 本期` | 通用查询，不加期数可查看列表 |
| 原神快捷 | `#本期深渊图鉴`、`#上期深渊图鉴`<br>`#本期幻想图鉴`、`#上期幻想图鉴`、`#下期幻想图鉴` | 也支持 `深境螺旋`、`幻想真境剧诗`、`剧诗` |
| 星铁快捷 | `#星铁本期混沌图鉴`、`#星铁上期混沌图鉴`、`#星铁下期混沌图鉴`<br>`#星铁本期虚构图鉴`、`#星铁本期末日图鉴`<br>`#星铁本期异相图鉴` | 也支持 `混沌回忆`、`忘却之庭`、`虚构叙事`、`末日幻影`、`异相仲裁` |
| 绝区零快捷 | `#绝区零本期防卫战图鉴`、`#绝区零上期防卫战图鉴`、`#绝区零下期防卫战图鉴`<br>`#绝区零本期危局图鉴`、`#绝区零上期危局图鉴` | 也支持 `式舆防卫战`、`危局强袭战` |

> 提示：可在快捷指令中指定具体日期（需包含期数），例如 `#2025年1月1日本期深渊图鉴`。若快照中缺少可验证的轮换时间，系统会提示轮换时间待核对，此时可使用记录 ID 直接查询。


## 三、角色攻略

| 游戏 | 命令格式 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| 原神 | `#<角色名>攻略` 或 `#<角色名>一图流`<br>`#<角色名>攻略1` 至 `#<角色名>攻略7` | `#胡桃攻略`<br>`#芙宁娜攻略1` | 可追加数字 1~7 指定攻略来源 |
| 星铁 | `#星铁<角色名>攻略` 或 `*<角色名>攻略`<br>`#星铁<角色名>攻略0`~`3` / `all` | `#星铁黄泉攻略`<br>`*流萤攻略all` | 可指定来源 0~3 或 `all` |
| 绝区零 | `#绝区零<角色名>攻略` | `#绝区零星见雅攻略` | 查询绝区零角色攻略 |
| 帮助 | `#攻略帮助` 或 `#原神攻略帮助` | `#攻略帮助` | 查看支持的攻略来源说明 |

> 提示：查询主角攻略时，需指定具体属性（如 `#风主攻略`、`#草主攻略`、`#星铁火主攻略`、`#星铁虚数主攻略`）。


## 四、参考面板与收益曲线

用于查看角色的毕业参考面板、词条收益曲线及配装建议（当前支持原神与星铁）。

| 功能 | 命令格式 | 示例 |
| :--- | :--- | :--- |
| 原神参考面板 / 收益曲线 | `#<角色名>参考面板`<br>`#<角色名>收益曲线`<br>`#<角色名>进阶攻略` | `#胡桃参考面板`<br>`#雷电将军收益曲线` |
| 星铁参考面板 / 收益曲线 | `#星铁<角色名>参考面板`（或 `*<角色名>参考面板`）<br>`#星铁<角色名>收益曲线`<br>`#星铁<角色名>进阶参考` | `*希儿参考面板`<br>`#星铁黄泉收益曲线` |
| 星铁旧版历史参考面板 | `#星铁历史<角色名>参考面板`（或 `*历史<角色名>参考面板`） | `*历史希儿参考面板` |
| 查看帮助与图例 | `#参考面板帮助`、`#收益曲线帮助`<br>`#星铁参考面板`、`#星铁历史参考面板帮助` | `#参考面板帮助`<br>`#星铁参考面板` |

> 区分提示：`*希儿参考面板` 查询的是公共配装参考；而 `*希儿面板` 查询的是你自己的角色面板。


## 五、原神配队与突破材料

### 1. 原神配队
- 命令格式：`#<角色名或队伍名>配队`（如 `#胡桃配队`、`#雷国配队`）。
- 限制：仅支持原神，不支持星铁或绝区零配队查询；查询旅行者配队需指定元素（如 `#风主配队`、`#草主配队`）。

### 2. 突破材料
- 命令格式：`#<角色名>突破` / `材料` / `素材` / `培养`（星铁角色需加 `星铁` 前缀，如 `#星铁流萤突破`）。
- 限制：暂不支持绝区零角色及主角（旅行者/开拓者）的突破素材图；若暂无原素材图，可使用角色详情快捷指令（如 `#胡桃图鉴`）查看养成材料。

## 七、常见失败与异常说明

1. 资源不存在或未收录
   - 图鉴、攻略、参考面板、配队、突破材料与复刻表均依赖本地已初始化的资源包或快照。若提示“暂无……资料/攻略/配队”或“图鉴条目详情不可用”，说明当前资源包尚未收录该条目或本地资源尚未就绪，可发送 `#图鉴状态` 查看当前图鉴版本。
2. 多页合并转发失败
   - 角色图鉴、套装图鉴、多图攻略、配队与复刻表在内容较多时，可能会通过合并转发发送。
   - 若当前聊天环境不支持合并转发或转发失败，请按系统实际提示处理（例如提示“合并转发结果未确认，请在聊天中核对”）。
3. 单图超过大小上限
   - 当生成的日历、突破素材图或图鉴单页超过当前聊天平台的单图大小上限时，系统会提示超过图片大小上限，或在日历等场景下自动降级为纯文本摘要返回。
