# 实用工具

本页介绍表情合成、图片文字识别、引用图片工具及群聊常用工具。系统信息查询命令见 [基础命令](/yunzai/docs/user/basics)，功能开关、前缀与权限设置见 [配置说明](/yunzai/docs/operator/configuration)，环境与资源部署见 [部署说明](/yunzai/docs/operator/deployment)。

## 表情合成

表情功能的开关、访问权限、是否强制要求 `#` 前缀及模板隐藏/保护规则，均由 [配置说明](/yunzai/docs/operator/configuration) 控制；终端会话不支持生成表情。

### 列表、搜索与详情

以下查询命令的 `#` 前缀可省略，且均受表情功能开关与访问权限控制（`#表情帮助` 与 `#表情版本` 除外）：

- **查看列表**：发送 `#表情列表` 查看模板目录卡片（不可用时返回文字列表），或发送 `#表情列表 2` 查看第 2 页文字列表（默认第 1 页，每页 12 项）；不带页码时也可发送 `#meme列表`。
- **搜索模板**：发送 `#表情搜索 猫` 按关键词搜索可用模板；结果不超过 30 条时直接引用回复，超过 30 条时以合并转发发送。
- **查看详情**：发送 `#表情详情 拍`（或传入模板编号）查看所需的图片与文字数量、默认文本、标签、可选参数、预设/快捷命令及预览图。
- **随机生成**：发送 `#随机表情` 或 `#随机meme` 随机选取一个带默认文本的单图或单段文字模板生成图片（开启强制 `#` 前缀时不可省略 `#`）。
- **其他命令**：`#表情帮助`、`#表情版本`、`#表情统计`（均不可附带多余参数；`#表情帮助` 会按发送者是否为主人显示对应说明，`#表情统计` 统计各模板调用次数）。

### 生成步骤、参数与图片来源

1. **触发生成**：发送 `#关键词 [文字或参数]`（若未在配置中强制要求 `#` 前缀，也可省略 `#`）。需要多段文字的模板用 `/` 分隔各段文字（如 `#关键词 第一段 / 第二段`）；未填写文字时，按配置可自动使用目标用户昵称或随机填充默认文本。对不需要文字的模板，若附带无关纯文本将不会触发。
2. **附带参数**（可用 `#表情详情 编号或关键词` 查看具体参数说明）：
   - **井号参数**：使用 `#参数名 值` 的形式（如 `#关键词 #参数名 值`），参数值会持续到下一个 `#` 之前。
   - **选项参数**：使用模板支持的 `--选项 值`、`-短选项 值`、中文选项名或无值开关选项；参数值含空格时可用单引号或双引号包裹，布尔参数支持 `true`/`false`、`1`/`0`、`yes`/`no`、`on`/`off` 等常见值。
   - **预设或快捷词**：部分模板支持直接用预设关键词或固定句式快捷触发（可在 `#表情详情` 的“参数命令”中查看）。
3. **图片来源**（按模板需求收集，超出上限时截断）：
   - **引用消息图片**：回复带图消息并发送表情命令；若所回复的消息不含图片且当前消息也未带图，会改用被回复用户的 QQ 头像。
   - **当前消息图片**：在发送命令的同时附带图片（单张不超过 8 MiB，支持 PNG、JPEG、GIF、WebP）。
   - **QQ 头像**：通过 `@用户` 或写入 `@QQ号` 获取目标用户头像；若仍不足模板最低图片要求（或单图模板未提供图片），自动补充发送者自己的 QQ 头像（单张不超过 512 KiB）。若触发受保护模板且目标受保护，普通用户可能会被拒绝或被反转头像顺序。

## 图片文字识别（OCR）

仅使用本地识别引擎，支持在**非匿名群聊**和**好友私聊**中使用（受权限配置控制）。单张图片需为有效图片，且总像素不超过 1200 万、宽高单边不超过 4096 像素；同一时间全局仅处理一个识别任务，处理期间新请求会提示稍后重试。

- **引用或带图识别**：回复带图消息，或发送图片的同时发送 `#ocr`、`#提取文字` 或 `#取文字`（必须带 `#`，`ocr` 不区分大小写，不可附带其他文字）。若同时引用了带图消息且当前消息带图，优先识别引用消息中的第一张图片；每次仅识别第一张图片。
- **先发命令后发图**：不带图直接发送 `#ocr`、`#提取文字` 或 `#取文字` 后，机器人在 120 秒内等待当前会话中同一发送者的下一张带图消息并识别其第一张图片；等待期间发送 `取消` 或 `#取消` 可中止（以 `#`、`/`、`*`、`%` 开头的其他指令不会当作待识别图片）。

## 引用图片工具

在**群聊**或**好友私聊**中，**回复（引用）包含图片的消息**并发送以下独立命令（`#` 可选，不可附带其他参数），单次最多处理 10 张有效图片，且总大小不能超过当前会话上限：

- `#链接` / `链接`：获取每张引用图片的序号、字节大小、下载链接及图片预览；单张直接回复，多张以合并转发发送。
- `#大小` / `大小`：同上，返回每张引用图片的序号、字节大小、下载链接及预览。
- `#过期` / `过期`：重新发送引用消息中的图片以刷新有效性，并在确认发出后尝试撤回原图消息与本次触发命令消息（同一条触发消息不会重复处理）。

## 群聊工具

以下命令**仅限群聊**使用，必须带 `#` 且不可附带任何参数（附带参数不会响应）：

- `#cat`：获取随机猫图并以合并转发发送（单张不超过 2 MiB，支持 JPEG、PNG、GIF、WebP）。
- `#推荐软件`：获取果核剥壳（`ghxi.com`）电脑端与安卓端的推荐软件列表，以合并转发发送。
