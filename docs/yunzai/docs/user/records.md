# 游戏战绩与数据查询

[返回用户指南概览](/yunzai/docs/user/index)


## 数据范围与查询条件

- 个人账号同步数据：《原神》《崩坏：星穹铁道》《绝区零》的角色卡片、角色列表、挑战战绩、探索收集进度、原神背包以及绝区零母带存货均属于个人账号数据。查询时必须在本人 QQ 私聊或群聊会话中直接发起，且账号需要本人已在机器人中完成绑定、登录并同步对应游戏角色，无法代查他人账号。
- 群聊查询与自动撤回：游戏注册时间、原神生日画片领取、星铁模拟/差分宇宙与演算战绩，以及绝区零国际服角色资料与月报均支持本人在群聊中直接发起，相关群聊回复默认在 120 秒后自动撤回（已有更短撤回时限的保留原值）。
- 公共图鉴与攻略：角色图鉴、材料图鉴和玩法攻略属于公共资料，不依赖个人账号登录状态，可前往 [攻略查询](/yunzai/docs/user/guides) 查看。
- 原神个人成就进度：成就查漏与完成记录保存在本地档案中，需要手动导入 JSON 进度文件或文本，不承诺从官方自动同步。
- 账号绑定与档案编号：首次使用前请先按 [账号绑定与管理](/yunzai/docs/user/accounts) 完成绑定与登录。档案编号范围为 1 到 255；命令中不写档案编号时，默认使用当前游戏的默认档。

## 原神

### 常用命令一览

| 功能 | 常用命令示例 | 说明 |
| :--- | :--- | :--- |
| 个人角色卡片 | `角色`、`#角色卡片`、`#原神角色卡片 2` | 查看角色概览卡片，可附带档案编号 |
| 角色列表 | `#角色`、`#五星角色`、`#四星角色查询`、`#角色 100000001` | 支持按四星/五星筛选，或指定本人已同步的 UID |
| 探索/宝箱/供奉 | `#探索`、`#探索度`、`#宝箱`、`#尘歌壶`、`#声望 档案 2` | 查看宝箱统计、神瞳、尘歌壶及各地区探索与供奉 |
| 深境螺旋 | `#深渊`、`#上期深渊`、`#深渊12层`、`#原神本期深境螺旋 2` | 支持 `本期`/`上期`/`往期` 及指定 `9`–`12` 层 |
| 幻想真境剧诗 | `#剧诗`、`#上期剧诗`、`#幻想真境剧诗 2` | 支持 `本期`/`当期`/`上期`/`往期` |
| 幽境危战 | `#幽境危战`、`#上期幽境单人`、`#危战组队 2` | 支持 `本期`/`上期`/`往期` 及 `单人`/`组队`/`最佳` 模式 |
| 原神背包 | `#原神背包`、`#原神背包2` | 查询官方养成计算器返回的背包材料（`≥` 表示至少拥有该数量） |
| 成就目录/查漏 | `#成就目录`、`#成就查漏`、`#成就列表 2` | 查看本地成就分类目录与完成统计 |
| 成就分类查询 | `#成就 天地万象` | 查看指定成就分类的本地完成情况 |
| 成就导入 | `#成就导入`、`#成就录入 2` | 附带 `.json` 文件或粘贴 JSON 内容导入本地进度 |

### 原神成就导入步骤

- 准备好符合格式的成就导出 `.json` 文件或 JSON 文本。
- 发送 `#成就导入`（如需指定档案可加编号，如 `#成就导入 2`），同时附带 `.json` 文件或在命令后直接粘贴 JSON 内容。
- 若先发送了 `#成就导入` 且未附带内容，可在提示后继续发送 JSON 文件或文本完成录入。

| 功能 | 常用命令示例 | 说明 |
| :--- | :--- | :--- |
| 战绩名片与探索 | `#星铁卡片`、`#星铁探索`、`*卡片 2` | 查看活跃天数、解锁角色、成就、战利品与忘却之庭进度 |

## 常见失败原因与排查

- 提示“请先登录档案”或“没有已同步的角色”：当前档案尚未登录，或登录后未同步对应游戏的角色，请先前往 [账号绑定与管理](/yunzai/docs/user/accounts) 完成登录与角色同步。
- 提示“档案编号须在 1 到 255 之间”：命令中输入的档案编号超出了 1 到 255 的有效范围，请检查编号是否正确。
- 提示“档案已变化，请重新查询”：查询过程中切换了当前档案或重新登录了账号，重新发送一次查询命令即可。
- 提示“战绩未公开或暂无可查询的记录”：对应游戏账号在米游社的战绩隐私未公开，或当前周期尚未产生可查询的挑战记录。
- 提示“请在本人 QQ 会话中查询”：不可通过他人转发或非本人会话代查个人数据，请在本人私聊或群聊中直接发送命令。
- 原神背包提示“没有返回可查询的背包材料”：官方养成计算器接口当前未返回可用材料数据，请确认账号在官方工具中已正常启用。
