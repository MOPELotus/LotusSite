# 音乐与点歌

本页介绍群聊与私聊中的点歌、播客、MV、歌词语音获取，以及机器人主人使用的公共音乐账号登录、网易云盘与音乐合伙人功能。涉及机器人主人底层配置的内容，请参见 `../operator/configuration.md`。

## 点歌与搜索

### 支持的平台

点歌支持以下平台（括号内为命令可用的平台别名）：

- **网易云音乐**：`网易云`、`网易`（默认平台）
- **QQ 音乐**：`QQ音乐`、`QQ`、`qq`
- **酷狗音乐**：`酷狗`
- **酷我音乐**：`酷我`
- **咪咕音乐**：`咪咕`
- **汽水音乐**：`汽水`
- **哔哩哔哩**：`哔哩哔哩`、`哔哩`、`B站`、`b站`（搜索公开视频音轨）

### 搜索点歌与直接播放

1. **搜索点歌**
   - 语法：`#[平台]点歌 <关键词>` 或 `#[平台]搜歌 <关键词>`
   - 示例：
     - `#点歌 晴天`（使用默认平台，通常为网易云）
     - `#QQ点歌 晴天`
     - `#酷狗搜歌 晴天`
     - `#B站点歌 关键词`
   - 网易云播客搜索：`#点歌 <关键词> 2`（仅限网易云平台，关键词与 `2` 之间需有空格）

2. **直接播放首条结果**
   - 语法：`#播放 <关键词> [1|2]`
   - 示例：
     - `#播放 晴天` 或 `#播放 晴天 1`（直接播放首条歌曲）
     - `#播放 关键词 2`（仅限网易云，直接播放首期播客）
   - 也支持 `#播放 <原文链接>` 直接请求完整音源或 MV。

3. **自然语言点歌**
   - 语法：`[平台]点歌/点播/播放/放一首/来一首 <关键词>`
   - 示例：`来一首晴天`、`QQ点歌 晴天`、`点播 晴天`
   - 边界：不带 `#` 且不带平台名时，若动词为 `点播`、`点歌`、`播放`，后面必须有空格或冒号分隔；关键词长度不超过 150 字，且不能是链接或无关媒体词。

4. **多选点歌（跨页连选）**
   - 语法：`#多选[平台]点歌 <关键词>` 或 `#[平台]多选点歌 <关键词>`
   - 示例：`#多选点歌 晴天`、`#QQ多选点歌 晴天`
   - 说明：每页显示 20 条，最多保留 500 条结果。跨页保留编号，回复数字可选一首并反复选择。

### 选歌、翻页与取消

搜索结果发出后，在会话有效期内（普通搜索默认 2 分钟，多选模式默认 3 分钟）可进行以下操作：

- **选歌**：直接回复列表中的数字（如 `1`），或发送 `#听1`（`#听` 与数字之间无空格）
- **翻页**：发送 `#下一页`、`#音乐下一页`（普通搜索中直接回复 `下一页` 也可）
- **取消**：发送 `#取消` 或 `#音乐取消`

### 播放、歌词与语音

- **播放形式**：默认发送音乐卡片（若当前适配器支持且满足条件）与完整语音（WAV 格式）。若音频超过 16 MiB 内联上限，将尝试作为文件发送。
- **获取歌词或重发语音**：
  - 语法：`#歌词 [序号]`、`#语音 [序号]`、`#高清语音 [序号]`（不带 `#` 也可）
  - 选曲播放后，直接发送 `#歌词` 或 `#语音` 即可获取当前曲目的歌词或重发语音。
  - 在搜索列表未选曲时，可附带列表序号，例如 `#歌词 1`、`#语音 2`。
  - 边界：B 站视频音轨没有曲目歌词；网易云播客可通过 `#歌词` 获取节目字幕；若当前网关仅支持普通语音，`#高清语音` 会提示并尝试重发完整音源。

### 音乐分享链接识别

在群聊或私聊中直接发送以下平台的分享链接，机器人会自动解析并发送预览卡片：

- **支持解析并播放完整音源/MV**：网易云（单曲、播客、MV、`163cn.tv` 短链）、QQ 音乐（单曲、MV）、酷狗（单曲、MV、分享页）、酷我/波点（单曲、MV）、汽水音乐（单曲、`qishui.douyin.com/s/...` 短链）。发送 `#播放 <原文链接>` 可请求完整音源或 MV。
- **仅支持预览**：Apple Music（`music.apple.com`）与 Spotify（`open.spotify.com`）仅支持读取并预览曲目信息，无法直接播放，需在原平台打开。

### QQ 音乐推荐与个人收藏

- `#来首歌` / `#放首歌` / `#来一首歌` / `#放一首歌`：随机获取一首 QQ 音乐推荐歌曲。
- 以下指令仅限具有主人或包管理权限的用户在**本人好友私聊**中使用：
  - `#我的收藏 [页码]` / `#我喜欢的歌 [页码]`（默认第 1 页，每页 10 首）
  - `#个性电台`
  - `#每日推荐` / `#每日30首` / `#日推`

## 公共音乐账号管理（仅机器人主人私聊）

以下指令仅限具有主人或包管理权限的用户在**本人好友私聊**中使用：

- **扫码登录**：`#音乐登录`（优先复用已绑定登录）、`#音乐重新登录`（强制重新扫码）。发送后按提示回复平台序号（部分平台如 QQ、酷狗需再选扫码方式），使用对应 App 扫码即可。网易云账号与合伙人、云盘共用。
- **查看登录状态**：`#音乐登录状态`（或 `#点歌ck状态`、`#音乐cookie状态`），可检查 QQ 与网易云的登录有效性。
- **刷新登录**：`#刷新<平台>音乐登录`，支持 `网易云`、`QQ`、`酷狗`、`汽水`、`酷我`、`咪咕`。示例：`#刷新网易云音乐登录`。

## 网易云盘（仅机器人主人私聊）

需先在私聊通过 `#音乐登录` 绑定网易云账号，方可使用以下指令（均仅限机器人主人在私聊中使用）：

- **查看与搜索云盘**：`#我的云盘 [关键词] [第N页]`（别名 `#rnc`、`#云盘搜索`），每页显示 10 首。
  - 示例：`#我的云盘`、`#我的云盘 晴天`、`#我的云盘 第2页`
- **翻页**：`#云盘下一页`、`#云盘上一页`
- **播放云盘曲目**：`#听云盘 <本页序号>` 或 `#播放云盘 <本页序号>`，示例：`#听云盘 1`
- **云盘匹配官方歌曲**：`#云盘匹配 <本页序号> <网易云单曲链接或歌曲编号>`
  - 示例：`#云盘匹配 1 186016`、`#云盘匹配 1 https://music.163.com/#/song?id=186016`
- **上传音频到云盘**：发送音频文件时附带 `#上传云盘`（别名 `#上传网盘`、`#rnu`），或引用自己发送的音频文件后回复 `#上传云盘`。
  - 格式与大小限制：支持内容与扩展名一致的 `FLAC`、`MP3`、`WAV`、`OGG`、`M4A`，文件大小不超过 16 MiB。
- **缓存管理**：`#云盘更新`（或 `#更新云盘`）刷新云盘列表；`#清除云盘缓存` 清除本地缓存。

## 网易云音乐合伙人（仅机器人主人）

### 常用指令

- **合伙人登录**（仅主人私聊）：`#合伙人登录`
  - 扫码登录网易云账号后，将自动启用合伙人定时任务。
- **查看最近日志**（仅主人私聊）：`#合伙人日志`
  - 以合并转发形式展示最近一次任务的执行摘要与每首歌曲的评分、乐评状态。
- **手动执行**（仅主人）：`#合伙人测试` 或 `#合伙人测试(执行)`（全角括号 `（执行）` 亦可）
  - 两者进入相同执行流程，均会**真实提交**评分与乐评，没有仅干跑（dry-run）的测试模式。
- **服务状态与初始化**（仅主人）：`#TuneWeave状态`、`#初始化TuneWeave`

### 评分与乐评生成

合伙人任务中，**评分**与**乐评**相互独立（配置项参见 `../operator/configuration.md`）：

- **评分**：由本地按权重随机生成（3 分与 4 分各占 35%，2 分占 20%，5 分占 10%）；AI 乐评模式不负责评分。
- **固定乐评（`fixed` 或未配置）**：从配置的 `comments` 列表中随机抽取一条发送（默认上限 140 字）。
- **Codex CLI 模式（`codex`）**：
  1. 先拉取歌曲详情、歌词与歌手简介作为参考上下文。
  2. 调用本机 `codex` CLI（只读沙盒模式，启用实时联网搜索，禁用 Shell 工具）生成结构化短评与来源 URL。
  3. 仅当 CLI 实际执行了 `web_search` 事件且成功、未超时、且返回的 `comment`（20 至 `max_chars` 字，默认上限 140）与 `sources` 均通过校验时，才会随评分一同发布乐评。
  4. 若资料不足、未执行联网搜索或校验未通过，**评论将留空，但评分仍会继续提交**。
- **Responses API 模式（`responses`）**：通过配置的 API 接口调用模型并强制启用 `web_search` 核对后生成短评，同样需通过来源与字数校验才会发布，否则评论留空但评分继续提交。

### 自动任务前提

1. 需在配置中开启 `netease_partner.enable: true`（参见 `../operator/configuration.md`）。
2. 默认按 `schedule`（默认 `0 30 1 * * ? *`，即每天 01:30）自动执行，每日最多执行一次。
3. 若开启 `auto_catch_up: true`，当机器人启动就绪时已过当日定时时间点且当日尚未执行过任务，将在等待 60 秒及开机环境维护完成后自动执行一次启动补跑。
4. 任务完成后默认向主人发送结果通知（可通过 `notify_master: false` 关闭）。
