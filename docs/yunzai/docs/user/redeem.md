# 兑换码使用

本指南介绍如何使用机器人查询前瞻兑换码、开启或关闭前瞻码自动兑换、手动兑换国际服兑换码，以及查询米游币余额和使用米游币商城网页端。

查询前瞻兑换码无需登录；如需执行自动兑换、手动兑换、米游币查询或使用网页商城等账号相关操作，请先完成[账号绑定与管理](/yunzai/docs/user/accounts)中的登录绑定。自动兑换结果通知与[每日签到](/yunzai/docs/user/checkin)共用档案的通知设置。

---

## 1. 前瞻兑换码查询

用于查询官方前瞻直播或特别节目发布的兑换码及对应奖励。

### 可用命令与输入示例
- **按默认前缀查询**：
  - `#兑换码`（默认查询原神）
  - `*兑换码`（星穹铁道）
  - `%兑换码` 或 `％兑换码`（绝区零）
  - `/兑换码`（默认查询原神）
- **按游戏名称或别名查询**（后缀可为 `兑换码`、`直播兑换码`、`前瞻兑换码` 或 `code`）：
  - `#原神兑换码`、`#原神前瞻兑换码`
  - `#星铁兑换码`、`#崩铁直播兑换码`、`#星穹铁道code`
  - `#绝区零兑换码`、`#绝区前瞻兑换码`、`#zzz兑换码`
  - `#崩坏3兑换码`、`#崩三直播兑换码`、`#崩坏三兑换码`
- **特殊活动查询**：
  - `#星布谷地公测兑换码`

### 使用限制与结果说明
- **适用范围**：群聊与好友私聊均可使用，无需登录档案。
- **支持范围独立**：前瞻查码与自动兑换的支持范围相互独立，例如**崩坏3**支持查询前瞻兑换码，但不支持自动兑换。
- **返回结果**：若当前有可用兑换码，机器人会以合并转发消息发送兑换码与奖励说明；若查询原神或星穹铁道且已启用手动兑换功能，消息末尾会附带国际服手动兑换命令提示。

## 2. 前瞻码自动兑换（开启与关闭）

开启后，机器人会在检测到国服前瞻兑换码可用时，自动为对应档案提交兑换，并按该档案的[每日签到](/yunzai/docs/user/checkin)通知设置发送结果。

### 可用命令与输入示例
- **开启自动兑换**：
  - `#注册自动兑换前瞻兑换码`（默认档案 `1`）
  - `#注册自动兑换前瞻码2`（指定档案 `2`）
  - 支持将后缀写为 `前瞻兑换码`、`前瞻码`、`前瞻（兑换码）` 或 `前瞻(兑换码)`。
- **关闭自动兑换**：
  - `#关闭自动兑换前瞻兑换码`（默认档案 `1`）
  - `#关闭自动兑换前瞻码2`（指定档案 `2`）
- **参数说明**：末尾数字为档案编号，范围 `1` 到 `255`，不填默认 `1`。

### 前置条件与权限限制
- **会话与授权要求**：建议在**机器人好友私聊**中发送注册或关闭命令；群聊中仅当具备本人可信的私密凭据会话授权时可用，不支持委托会话或终端操作。
- **登录要求**：开启前，对应档案必须已完成登录。
- **权限要求**：开启自动兑换需要具备注册权限（由机器人[配置说明](/yunzai/docs/operator/configuration)决定，无权时会提示当前会话无权注册）。
- **本地授权与旧版导入**：
  - 本人显式发送 `#注册自动兑换前瞻兑换码` 并通过权限校验后，系统会写入本地授权标记，即使旧兑换记录丢失也可直接恢复授权并正常运行，无需补齐旧记录。
  - 若档案是从旧版导入且仅带有启用标记、缺少本地授权标记，只要仍存在有效的旧兑换记录，系统会继续按去重记录运行；仅当本地授权标记与旧兑换记录同时缺失时，才会阻止自动扫描，此时需由本人重新发送注册命令恢复授权。
- **关闭范围说明**：发送关闭命令仅关闭当前档案的前瞻码自动兑换设置，**不会**清除已绑定的 Cookie/SToken，也不影响每日签到功能。

### 支持范围与去重限制
- **支持游戏与服务器**：仅支持 **原神、星穹铁道、绝区零** 的 **国服**（如官服与 B 服区服）。
- **角色选择**：若档案已设置选定 UID，则兑换到该角色；否则仅在目标游戏区服下唯一存在 1 个角色时自动选择。
- **去重与中断**：系统按“账号 + 游戏 + 版本号 + UID”记录兑换状态，同一版本同一角色不会重复提交。若某条兑换码返回被拦截（`blocked`）或结果未确认（`unknown`），将停止本轮后续兑换码的提交，且不会自动反复重投。

## 3. 国际服兑换码手动兑换

用于将国际服兑换码直接提交到已绑定的 HoYoLAB 档案角色。

### 可用命令与输入示例
- **命令格式**：`[#*%％][原神|星铁|绝区零]兑换码使用 <兑换码> [档案N]`（也可将 `兑换码使用` 替换为 `cdk-u`）
- **输入示例**：
  - `#兑换码使用 <兑换码>`（默认原神，档案 `1`）
  - `*兑换码使用 <兑换码> 档案2` 或 `#星铁兑换码使用 <兑换码> 档案2`（星穹铁道，档案 `2`）
  - `#原神cdk-u <兑换码>`
- **参数说明**：
  - `<兑换码>`：待兑换的兑换码字符串。
  - `档案N`：可选，范围 `1` 到 `255`，不填默认 `1`。

### 前置条件与限制
- **会话限制**：**仅限机器人好友私聊**使用，群聊、委托会话或终端均不可用。
- **登录要求**：对应档案须已绑定并核验 HoYoLAB Cookie（星穹铁道还需具备活动 Cookie）。
- **角色确定**：系统会按“档案选定 UID → 仅 1 个角色 → HoYoLAB 默认选中角色”的顺序确定目标角色；若无法唯一确定，需先在 HoYoLAB 选择默认角色后再试。
- **绝区零不支持**：绝区零国际服暂不支持通过机器人命令手动兑换（发送 `%兑换码使用` 或 `#绝区零兑换码使用` 会提示请在游戏内兑换）。
- **防重复提交**：同一账号、游戏、区服及角色 UID 下，相同兑换码不可重复提交。

## 4. 米游币查询

用于查看指定档案当前的米游币总余额及今日剩余可获取数量。

### 可用命令与输入示例
- `#米游币查询` 或 `#米币查询`（默认档案 `1`）
- `#米游币查询2`（指定档案 `2`，范围 `1` 到 `255`）

### 前置条件与结果
- **前置条件**：对应档案须已登录。若 Cookie 过期、登录失效、触发风控或查询过于频繁，将返回对应提示。
- **返回结果**：显示当前米游币数量与今日剩余可获取数量；查询非 `1` 号档案时，结果首行会标明档案编号。

## 5. 米游社网页商城与功能入口

通过私聊获取专属一次性网页链接，在浏览器中管理米游社功能、查看商品、预约兑换或设置持续追踪。

### 可用命令与输入示例
- `#米游社功能`（默认档案 `1`，打开功能首页）
- `#米游币兑换` 或 `#米游币商城`（默认档案 `1`，在商城可用时直接定位到商城标签页）
- `#米游币商城2`（指定档案 `2`，范围 `1` 到 `255`）

### 前置条件与限制
- **会话限制**：**仅限机器人好友私聊**使用，群聊、委托会话或终端不可用。
- **登录与配置**：对应档案须已扫码登录，且机器人已配置可用的米游社功能页访问地址（详见[配置说明](/yunzai/docs/operator/configuration)）。
- **链接有效期**：生成的链接具有时效性且**只能使用一次**，浏览器登录后可在会话有效期内使用，请勿转发他人。

## 6. 米游币商城兑换规则与限制

在网页商城中进行立即兑换、定时预约或持续追踪时，需遵守以下规则与限制：

### 商品类别与兑换目标
- **实物商品**：支持立即兑换、定时预约与持续追踪；兑换时须选择当前档案下已有的收货地址。
- **游戏虚拟商品**：支持立即兑换、定时预约与持续追踪（持续追踪支持原神、星穹铁道、绝区零、崩坏3、崩坏2、未定事件簿六个游戏分区）；兑换时须选择当前档案下对应游戏区服的绑定角色（UID 与区服）。
- **社区虚拟商品**（米游社社区分区商品）：支持立即兑换与定时预约，直接兑换到当前米游社账号，无需选择游戏角色或收货地址；**不支持**持续追踪。

### 余额、限购与库存检查
- **余额校验**：提交预约或追踪自动下单前，会核验米游币余额是否足够支付商品价格。
- **状态与限购**：浏览商城列表与详情时可查看各状态商品；其中**立即兑换**仅支持状态为“可兑换”的商品，**定时预约**支持“可兑换”或“已排期”的商品。若账号已达该商品本轮限购上限（如日/周/月/批次/永久限购），将不会提交兑换。

### 预约兑换与时间窗口
- **明确确认**：每次预约或立即兑换均须明确确认并选定兑换目标；若商品价格或档案绑定的账号/设备发生变化，须刷新后重新确认。
- **时间窗口**：预约计划会在商品开放前进入准备状态（默认提前 15 秒），并在开放后最多 30 秒的时间窗口内尝试提交；错过窗口会标记为“已错过”。
- **立即兑换验证**：立即兑换若触发人机验证，须在当前网页会话有效期内完成验证；若网页会话提前结束，未提交的立即兑换将被取消。

### 持续追踪与预算控制
- **追踪模式**：
  - **指定商品模式**：最多添加 `20` 个商品 ID，可选是否“跟随同名商品”。
  - **分区关键词模式**：按游戏分区与商品类型匹配，最多设置 `10` 个关键词；多个关键词满足**任一包含**即命中，留空则匹配所选分区下的所有商品。
- **可选参数与限制**：
  - 单件最高价格上限、累计预算上限（含已成功花费及进行中/待确认占用）均**可选**设置。
  - 轮询间隔：`1` 到 `1440` 分钟。
  - 提前准备时间：`0` 到 `30` 秒。
  - 兑换重试间隔：`250` 到 `5000` 毫秒。
- **自动暂停**：遇到账号触发风控验证、商城请求频繁或档案换绑时，追踪规则会自动暂停。

### 未知结果人工核对限制
- 若兑换请求已发出但未能确认最终结果，该计划会进入 **结果待确认（`unknown`）** 状态。
- **限制影响**：
  - 在存在待确认结果期间，同一账号下的**持续追踪会自动暂停**，且无法创建或恢复追踪。
  - 同一账号下的**同一商品**若已有进行中或待确认的计划，无法重复新建预约。
- **解除方式**：请先前往米游社官方兑换记录核对实际结果，并在网页端人工确认“已兑换”或“未兑换”后，方可恢复后续操作。
