# 角色面板查询

[返回用户指南概览](/yunzai/docs/user/index)

## 一、数据来源与缓存机制

在查询角色面板或计算伤害前，需要先了解机器人获取数据的两种途径与本地缓存的区别：

1. 米游社全角色面板：通过绑定米游社账号（Cookie）拉取账号下全部已解锁角色的面板、武器与圣遗物/遗器/驱动盘信息，适合查看未放入展柜的角色。
2. 公开展柜 / 展板：通过游戏 UID 拉取游戏内“角色展柜”公开展示的少数角色（《崩坏：星穹铁道》《绝区零》均支持展柜独立指令）。
3. 本地已有缓存：每次成功更新面板后，数据会缓存在本地。后续查看角色详情、计算个人伤害或队伍伤害时，优先读取本地缓存；如果游戏内更换了装备，需要重新执行更新指令。若需要清理旧数据，可使用重载指令刷新读取，或使用删除指令清除本地数据（删除后需要重新执行更新指令拉取）。

先决条件：使用米游社全角色更新前，需先登录对应档案并选择该游戏角色（详见[账号绑定与管理](/yunzai/docs/user/accounts)）。个人伤害与队伍伤害计算以角色正确绑定为前提，若本地已有本人的有效面板缓存，即使暂未持有活跃 Cookie 也可能正常测算。

## 二、原神面板、换装与队伍伤害

### 1. 常用面板指令

| 功能 | 指令示例 | 说明 |
| :--- | :--- | :--- |
| 更新全角色面板 | `#更新面板` / `#全部面板更新` | 从米游社拉取全部角色数据 |
| 重载本地缓存 | `#重载面板` | 重新读取本地已保存的面板文件 |
| 删除面板缓存 | `#删除面板` | 清除当前档案的本地面板数据（清除后需重新更新） |
| 查看面板列表 | `#面板` / `#面板列表` | 查看已缓存的角色列表 |
| 查看圣遗物列表 | `#圣遗物列表` | 查看当前档案的圣遗物汇总 |
| 查看角色面板 | `#胡桃面板` / `#胡桃详情` | 支持 `#100000000胡桃面板` 指定 UID |
| 查看个人伤害 | `#胡桃伤害` / `#胡桃武器` | 测算当前缓存角色的技能伤害 |

### 2. 个人伤害行号与档案冲突处理

在原神中，`#胡桃伤害` 后紧跟的数字会被识别为伤害行号（`#胡桃武器` 后紧跟的 1~7 会被识别为武器对比行）。若同时需要指定多账号档案，请务必使用 `档案 <编号>` 隔开，避免数字被误判为行号：

- 查看默认档案第 2 行伤害：`#胡桃伤害2`
- 查看档案 2 的默认伤害：`#胡桃伤害 档案 2`
- 查看档案 2 的第 1 行伤害：`#胡桃伤害1 档案 2`

### 3. 临时换装对比

原神支持基于本人同档案中已保存的角色面板进行临时换装试算（指令中需包含“换”字）。你可以为角色临时更换指定武器（包括使用“专武”指代）或借用同一档案内其他已缓存角色身上的圣遗物，从而对比换装前后的面板与伤害变化：

- 借用同档案其他角色指定部位的圣遗物（支持花/羽/沙/杯/冠）：`#胡桃伤害换香菱花`（仅借用花部位；需同一档案内胡桃与香菱均已缓存面板）

### 4. 队伍伤害计算

支持通过角色组合或内置队伍别名计算四人队伍的协同伤害，并可附加 `详情`、`过程`、`全图` 查看详细输出：

- 自由组合：`#队伍伤害 雷电将军 九条裟罗 枫原万叶 班尼特`
- 使用内置别名：`#队伍伤害 雷国`（支持 `雷九`、`胡行夜钟`、`神鹤万心`、`妮绽放`、`草国` 等常见配队）
- 查看详情与指定档案：`#队伍伤害详情 雷国 档案 2` 或 `#队伍伤害2 雷国`

## 三、崩坏：星穹铁道面板、换装与队伍伤害

星铁指令支持 `#星铁` 或 `*` 作为前缀。

### 1. 常用面板指令

| 功能 | 指令示例 | 说明 |
| :--- | :--- | :--- |
| 更新米游社面板 | `#星铁更新面板` / `*更新面板` | 拉取米游社全角色面板 |
| 更新公开展柜 | `#星铁展板更新面板` / `*更新黄泉面板` | 拉取游戏内公开展柜数据 |
| 刷新行迹/天赋 | `#星铁刷新行迹` / `*更新天赋` | 单独更新角色行迹等级 |
| 重载 / 删除缓存 | `*重载面板` / `#星铁删除面板` | 管理本地面板缓存（删除后需重新更新） |
| 查看面板 / 遗器列表 | `*面板` / `#星铁遗器列表` | 查看已缓存的角色或遗器 |
| 查看角色面板 | `#星铁黄泉面板` / `*黄泉详情` | 查看单个角色的详细属性 |
| 查看个人伤害 | `#星铁黄泉伤害` / `*黄泉武器` | 测算当前角色的个人伤害 |

### 2. 个人伤害行号与档案冲突处理

星铁伤害指令中，紧跟在 `伤害` 后的数字会被识别为伤害行号，空格后的数字才会被识别为档案编号：

- 查看默认档案第 2 行伤害：`*黄泉伤害2`
- 查看档案 2 的第 1 行伤害：`*黄泉伤害1 2`

### 3. 临时换装与星魂试算

星铁支持基于本地已缓存的角色面板进行临时星魂调整、更换光锥或借用同档案其他角色的遗器/光锥进行伤害或面板试算：

- 临时调整星魂：`#星铁黄泉伤害换6魂`
- 借用同档案其他角色的光锥：`#星铁黄泉伤害换景元光锥`（需同一档案内两位角色均已缓存面板）

### 4. 队伍伤害计算

星铁支持 `#星铁队伍伤害`、`*队伤`、`#星铁伤害`（可附加 `详情`、`过程`、`全图`），并支持指定轮次（默认 5 轮）与敌方目标数（默认 3 敌）：

- 使用别名：`*队伤 黄泉队`（支持 `飞托阮同`、`追击队`、`黑塔队` 等）
- 指定轮次与目标数：`#星铁队伍伤害 追击队 5轮 1怪`
- 指定档案：`*队伤2 黄泉队` 或 `#星铁队伍伤害 黄泉队 档案 2`

## 四、绝区零面板与伤害

绝区零指令支持 `#zzz`、`#绝区零` 等前缀。

### 1. 常用面板指令

| 功能 | 指令示例 | 说明 |
| :--- | :--- | :--- |
| 更新米游社面板 | `#zzz更新面板` / `#zzz更新星见雅面板` | 拉取米游社全角色或指定角色 |
| 更新公开展柜 | `#zzz刷新展柜面板` | 拉取游戏内公开展柜数据 |
| 查看面板列表 | `#zzz面板` / `#zzz面板列表` | 查看已缓存的代理人列表 |
| 查看练度统计 | `#zzz练度` / `#zzz展柜练度统计` | 汇总角色练度情况 |
| 查看角色面板 | `#zzz星见雅面板` | 查看米游社缓存面板 |
| 查看展柜角色 | `#zzz星见雅展柜面板` | 查看公开展柜中的角色面板 |
| 查看个人伤害 | `#zzz星见雅伤害` | 测算已适配代理人的技能伤害 |

### 2. 技能编号与档案冲突处理

在绝区零中，如果只写 `#zzz星见雅伤害2`（不写 `技能` 也不写 `档案`），数字 `2` 会被优先识别为档案 2。若要同时指定技能编号与档案，请显式写出关键词：

- 查看档案 2 的默认伤害：`#zzz星见雅伤害2` 或 `#zzz星见雅伤害 档案 2`
- 查看档案 1 的第 2 个技能伤害：`#zzz星见雅伤害 技能 2 档案 1`

## 五、常见失败原因与排查

1. 提示“暂无面板数据”或找不到角色：请先确认是否已绑定对应游戏账号，并执行过一次 `#更新面板`（或对应游戏的更新指令）建立本地缓存。
2. 临时换装失败：原神与星铁的临时换装均要求目标角色及被借用装备的角色已在同一档案下保存了有效面板；若指定的武器或光锥名称无法识别，请检查名称是否正确。
3. 绝区零提示暂不支持伤害计算：目前绝区零伤害测算仅支持已适配的代理人，且需要本机具备与规则版本一致的计算资料。
4. 档案编号无效：三款游戏的档案编号均需在 `1` 到 `255` 之间，且不能同时在指令首尾重复指定两个档案编号。

### 群聊支持与面板导入导出

- 本人全服排名查询和幽境群榜授权支持群聊，相关群回复默认 120 秒后撤回。幽境群榜的授权与确认须在同一会话进行，且群内只能授权当前群。
- 面板文件导入导出、跨机器人数据交换仍仅限好友私聊。普通导出使用当前所选档案角色；显式发送 `#原神导出面板 100000042` 或 `*导出面板 100000042` 时，该 UID 必须属于当前游戏默认登录档案，且导出期间档案不能换号或失效。原来的 UID 签名验证入口已停用，不再提供导出授权。
