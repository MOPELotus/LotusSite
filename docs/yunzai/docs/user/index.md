# 用户指南概览

[返回项目首页](/yunzai/) | [主人与开发者文档](/yunzai/docs/operator/index)

本指南面向在群聊或私聊中使用机器人的普通用户，整理了从初次上手到各类游戏查询、日常签到及群聊娱乐的完整说明。建议按照以下顺序逐步了解和使用各项功能。

## 一、快速上手与功能索引

如果您是第一次使用机器人，建议先从基础交互开始；如果您已经熟悉基本操作，可以直接通过功能跳转表查找所需指令。

- [基础功能](/yunzai/docs/user/basics)：介绍机器人的基本唤醒方式、常用基础指令以及常见使用规范。
- [常用功能跳转表](/yunzai/docs/user/commands)：按使用场景汇总高频功能，方便快速定位对应的说明页面。

## 二、账号绑定与管理

在使用角色面板、战绩查询、抽卡分析及自动签到等游戏相关功能前，需要先完成账号或角色信息的关联。

- [账号绑定与管理](/yunzai/docs/user/accounts)：说明扫码登录、档案选择、档案内角色切换，以及公开 UID 临时查询的边界。

## 三、游戏数据与攻略查询

完成账号绑定后，即可使用各类游戏数据查询与攻略检索功能：

- [角色面板查询](/yunzai/docs/user/panels)：获取已绑定角色的属性面板、圣遗物/装备评分及养成情况。
- [抽卡记录与分析](/yunzai/docs/user/gacha)：导入、导出并统计历史抽卡记录，查看出货分布与保底情况。
- [游戏战绩与数据查询](/yunzai/docs/user/records)：查询深渊/挑战战绩、日常体力与资源恢复状态等账号数据。
- [攻略查询](/yunzai/docs/user/guides)：检索角色培养路线、配队建议、材料需求及活动攻略。

## 四、每日签到与兑换

针对游戏日常福利与兑换需求，可参考以下专题：

- [每日签到](/yunzai/docs/user/checkin)：了解手动签到指令，以及开启自动签到与签到结果提醒的方法。
- [兑换码使用](/yunzai/docs/user/redeem)：查看当前可用的游戏兑换码，或直接通过机器人执行兑换操作。

## 五、群聊互动与实用工具

除游戏相关功能外，机器人还提供多种群聊娱乐与日常辅助功能：

- [音乐与点歌](/yunzai/docs/user/music)：在群聊中搜索歌曲、点歌播放及管理播放列表。
- [媒体与图片功能](/yunzai/docs/user/media)：进行以图搜图、图片处理及相关媒体内容获取。
- [群聊功能与互动](/yunzai/docs/user/group)：包含群内日常互动指令、趣味小游戏及部分群聊辅助功能。
- [实用工具](/yunzai/docs/user/tools)：提供翻译、天气查询、汇率换算等常用生活与信息查询工具。

## 其他说明

- 部分功能（如群聊互动、点歌或特定管理指令）可能受限于当前群聊的权限设置或机器人主人的全局配置。
- 如果您是机器人的部署者、管理员或开发者，需要了解安装、配置、定时任务及插件开发等内容，请前往 [主人与开发者文档](/yunzai/docs/operator/index)。
