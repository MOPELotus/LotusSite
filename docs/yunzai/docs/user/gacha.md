# 抽卡记录与分析

[返回用户指南](/yunzai/docs/user/index)




## 先决条件与通用规则

1. 账号与角色前提：更新或同步官方记录、获取或录入抽卡链接等需要访问官方接口的操作，需在当前 QQ 会话先完成对应档案的登录并同步目标游戏 UID；若本地已有缓存记录，部分查询或文件备份操作只需绑定对应角色即可（绑定与登录流程请参考[账号绑定与管理](/yunzai/docs/user/accounts)）。
2. 多档案切换：三游真实抽卡记录相关指令通常支持在命令末尾附加档案编号（1 至 255，不填默认使用当前游戏的默认档案），例如 `#角色全部记录2`、`%抽卡记录2`。（注意：模拟抽卡指令末尾的数字表示卡池编号，而非档案编号。）
3. 各游戏指令前缀并不统一：
   - 原神主要使用 `#` 前缀（多数查询命令也可省略 `#` 或加上 `原神`）。
   - 崩坏：星穹铁道记录类命令支持 `*`、`＊`、`#星铁` 等前缀（旧前缀 `*` 会自动识别并统一处理），模拟跃迁命令使用 `#星铁` 前缀。
   - 绝区零支持 `%`、`％`、`#绝区零` 等前缀。
4. 模拟抽卡前提：原神与星铁的模拟抽卡与真实游戏账号分开，无需绑定游戏 UID 即可在 QQ 会话使用（前提是机器人已开启对应模拟抽卡功能）。


## 三游抽卡功能总览

| 功能项目 | 原神 | 崩坏：星穹铁道 | 绝区零 |
| :--- | :--- | :--- | :--- |
| 同步官方记录 | `#更新抽卡记录` | `*更新抽卡记录`（仅国服汇总） | `%更新抽卡记录`（国服同步；国际服自动引导录链接） |
| 外部服务同步 | `#同步外部抽卡记录` | 不支持 | 不支持 |
| 获取抽卡链接 | 不支持 | 不支持 | `%获取抽卡链接`（仅私聊、国服可用） |
| 录入抽卡链接 | 不支持 | `*抽卡链接`（仅好友私聊） | `%抽卡链接`（仅私聊） |
| 逐抽与展示区分 | 本地统一保存记录 | 严格区分「展示汇总」与「本地逐抽」 | 区分「米游社汇总」与「逐抽链接记录」 |
| 文件导入 / 导出 | 支持 UIGF JSON | 支持 UIGF / SRGF JSON（仅真实逐抽可导出） | 当前提供功能不含导入与导出 |
| 模拟抽卡 | 支持（含武器定轨） | 支持（含多编号卡池、联动池、转生） | 不支持 |


## 原神祈愿记录

### 1. 更新与查询

| 指令示例 | 说明 |
| :--- | :--- |
| `#更新抽卡记录` | 同步当前档案官方可获取的祈愿记录并合并到本地 |
| `#同步外部抽卡记录` | 从提瓦特小助手同步外部祈愿历史 |
| `#抽卡记录` / `#武器记录` / `#常驻记录` / `#集录记录` | 查看对应卡池的祈愿记录 |
| `#新手记录` | 查看旧新手池本地记录 |
| `#全部记录` | 查看各卡池详情 |
| `#角色全部记录2` | 加「全部」查看该池各分页，末尾 `2` 表示查询档案 2 |
| `#版本统计` / `#全部统计` | `#版本统计` 按卡池期次查看角色与武器池，`#全部统计` 查看各池汇总 |
| `#抽卡帮助` | 查看原神抽卡指令说明 |
| `#电脑帮助` / `#安卓帮助` / `#苹果帮助` | 查看对应设备的登录与更新指引 |

### 2. 文件导入与导出（UIGF JSON）

原神支持以 UIGF 格式的 JSON 文件导入和导出本地历史记录，推荐在私聊中进行。

- 导入操作步骤：
  1. 私聊发送 `#导入记录`（如需指定档案可加编号，如 `#导入记录2`；若必须在群聊操作，需发送 `#强制导入记录`）。
  2. 收到提示后，在 2 分钟内直接发送 `.json` 文件（UTF-8 编码的 UIGF 文件）。
  3. 机器人校验当前档案 UID 一致后，将文件记录合并入本地历史并返回各池新增与总计条数。
- 导出操作步骤：
  1. 私聊发送 `#导出记录`（默认导出 UIGF v4 格式；如需旧版格式可发送 `#导出记录jsonv2`）。
  2. 若必须在群聊发送文件，需使用 `#强制导出记录`。
  3. 机器人将生成以 UID 命名的 `.json` 文件并上传到当前会话。


## 崩坏：星穹铁道跃迁记录

### 1. 展示历史与逐抽记录的区别

星铁在数据来源和本地存储上严格区分两套记录：

1. 展示用汇总记录（非逐抽）
   - 通过 `*更新抽卡记录` 或 `*更新跃迁` 从国服小程序获取，仅包含五星与垫抽汇总信息（部分旧档案也可能存有用于显示的占位记录）。
   - 可通过 `*抽卡记录`、`*版本统计` 等常规指令查看，但不能用于导出真实逐抽文件。
2. 本地逐抽档案（逐条记录）
   - 仅能通过 私聊 `*抽卡链接` 录入官方跃迁链接，或 私聊 `*导入记录` 导入 UIGF / SRGF 文件获得。
   - 只有本地逐抽档案才能通过 `*逐抽` 系列指令查看，也只有真实逐抽档案才能通过 `*导出记录` 导出。

### 2. 更新、查询与逐抽查看

| 指令示例 | 说明 |
| :--- | :--- |
| `*更新抽卡记录` / `*更新跃迁` | 更新国服小程序范围内的五星与垫抽汇总 |
| `*抽卡记录` / `*光锥记录` / `*常驻记录` | 查看对应卡池记录 |
| `*新手记录` / `*角色联动记录` / `*光锥联动记录` | 查看新手池或联动池记录 |
| `*全部记录` / `*版本统计` | 查看各池概览或按活动期次统计 |
| `*角色全部记录2` | 加「全部」查看该池各分页，末尾 `2` 表示档案 2 |
| `*逐抽记录` / `*逐抽版本统计` / `*逐抽全部记录` | 仅读取本地真实逐抽档案进行展示与统计 |
| `*跃迁记录` | 查看本地逐抽总览 |
| `*抽卡帮助` | 查看星铁抽卡指令说明 |

### 3. 私聊录入官方抽卡链接

星铁支持通过官方跃迁链接直接采集逐抽记录：

1. 在已连接机器人的好友私聊中发送 `*抽卡链接`（可加档案编号）。
2. 在 2 分钟内将本档案的完整星铁官方抽卡链接发送给机器人；如需中途放弃，可发送 `取消`。
3. 机器人校验登录与 UID 未变更后，将读取并合并新增逐抽记录，随后可使用 `*逐抽记录` 查看。

### 4. 文件导入与导出（UIGF / SRGF JSON）

- 导入：私聊发送 `*导入记录`（群聊需用 `*强制导入记录`），在 2 分钟内发送 UIGF 或 SRGF 格式的 `.json` 文件。注意：包含显示占位记录的文件无法作为真实逐抽导入。
- 导出：私聊发送 `*导出记录`（默认 v4，可选旧格式 `*导出记录jsonv2`；群聊需用 `*强制导出记录`）。若本地仅有汇总记录或占位记录，系统会拒绝导出并提示原因。


## 绝区零调频记录

### 1. 国服与国际服机制差异

| 指令示例 | 说明 |
| :--- | :--- |
| `%更新抽卡记录` | 国服档案同步米游社六个频段的调频数据；国际服档案会自动引导进入抽卡链接录入流程 |
| `%抽卡记录` / `%抽卡记录2` | 国服查看官方调频统计（登录可用时另发实时调频库存）；国际服绑定档案查看已有旧档案与链接录入合并的记录 |
| `%母带` / `#绝区零存货` | 直接查看本人当前实时调频库存 |
| `%逐抽记录` | 查看通过抽卡链接录入的逐抽记录及合并的旧档案 |
| `%抽卡帮助` | 查看绝区零抽卡指令说明 |

### 2. 私聊获取与录入抽卡链接

- 获取链接（仅国服、仅私聊）：私聊发送 `%获取抽卡链接`，机器人会为当前国服档案生成官方抽卡链接。
- 录入链接（国服/国际服通用、仅私聊）：
  1. 私聊发送 `%抽卡链接`。
  2. 按提示发送本档案有效的绝区零官方抽卡链接；如需中断操作，可发送 `取消`。
  3. 录入完成后，可通过 `%逐抽记录` 查看结果。

### 3. 导入导出支持情况

绝区零当前提供的功能中不含文件导入或文件导出，不支持通过发送 JSON 文件导入记录，也不能导出本地调频记录文件。


## 链接安全与数据完整性限制

1. 敏感链接务必私聊：星铁与绝区零的官方抽卡链接包含身份验证与授权参数，泄露后可能导致他人读取你的抽卡信息，请妥善保管。因此获取链接与录入链接均应在好友私聊中进行，切勿在群聊发送真实抽卡链接。
2. 不承诺拉取全部历史：无论是通过登录态同步还是官方抽卡链接拉取，都只能获取官方接口当前仍提供返回的数据范围；官方接口范围之外的更早期抽卡记录无法通过刷新或重新拉取找回。
3. 互补与限制：
   - 原神与星铁的早期记录可通过本地备份文件（UIGF / SRGF）导入合并来补全；原神还可通过 `#同步外部抽卡记录` 从外部服务同步。
   - 星铁仅靠 `*更新抽卡记录` 无法获得逐抽详情与可导出档案，若需要逐抽记录与备份导出，必须趁官方记录仍在可获取窗口内通过 `*抽卡链接` 录入或及时导出留档。
   - 绝区零无文件导入导出，已录入的逐抽记录与旧档案合并保存在本地。


## 原神与星铁模拟抽卡区别

两款游戏的模拟抽卡均为独立本地娱乐玩法（绝区零无模拟抽卡），核心差异如下：

| 对比维度 | 原神模拟祈愿 | 星铁模拟跃迁 |
| :--- | :--- | :--- |
| 常用指令 | `#单抽`、`#十连`、`#百连`（支持 `#模拟抽卡帮助`） | `#星铁单抽`、`#星铁十连`、`#星铁百连`（支持 `#星铁模拟抽卡帮助`） |
| 卡池类型 | 角色池、角色池 2（如 `#十连2`）、武器池（`#武器池十连`）、常驻池（`#常驻池十连`） | 角色池、光锥池（`#星铁光锥十连`）、常驻池（`#星铁常驻十连`）、Fate[UBW] 联动角色/光锥池（`#星铁联动十连`、`#星铁联动光锥十连`） |
| 卡池编号 | 角色池支持默认池与 `2` 池 | 角色池与光锥池支持 `1` 至 `4` 号卡池（如 `#星铁十连2`）；常驻与联动池不带编号 |
| 定轨机制 | 支持武器池定轨：`#定轨`、`#定轨1`、`#定轨查询`、`#定轨取消` | 无定轨机制 |
| 消耗道具与查询 | 纠缠之缘与相遇之缘；`#我的纠缠之缘` 查询余量 | 星轨专票与星轨通票；`#星铁我的星轨票` 查询余量 |
| 趣味玩法 | — | 内置 `#星铁转生`（随机抽取星铁角色或星神身份卡片，带冷却时间） |


## 常见失败与排查

| 提示或现象 | 常见原因 | 处理建议 |
| :--- | :--- | :--- |
| 提示「请先登录档案 / 没有同步 UID」 | 当前档案未登录，或未同步对应游戏的 UID | 先完成对应档案的登录与角色同步后再试 |
| 提示「档案角色已变化，请重新操作」 | 查询、导入导出或录链接期间切换了档案或默认角色 | 确认当前选中角色后重新发起指令 |
| 提示「访问过于频繁，请稍后再试」 | 短时间内触发官方接口频率限制 | 等待一段时间后再重试 |
| 提示导入/录入「会话已超时」 | 发送导入或链接指令后超过 2 分钟未发送文件或链接 | 重新发送对应指令并在时限内完成提交 |
| 星铁 `*导出记录` 提示无法导出 | 本地只有国服小程序的显示汇总或占位记录，没有真实逐抽档案 | 先在私聊通过 `*抽卡链接` 录入或 `*导入记录` 导入逐抽文件后再导出 |
| 模拟抽卡提示未开启多连抽 / 道具不足 / 达到上限 | 管理员关闭了多连抽、当日票数耗尽或已达每日抽卡上限 | 改用十连/单抽，或等待后续道具恢复后再抽 |
