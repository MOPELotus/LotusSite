# 群聊功能与互动

本指南适用于群友与群管理员，说明群聊管理、入群验证、违禁词与屏蔽词、消息词条、群公告及公开查询的常用命令与权限边界。涉及机器人主人全局配置、私聊运维与通知开关的内容，请参见 [主人配置指南](/yunzai/docs/operator/configuration)；部署相关说明请参见 [部署指南](/yunzai/docs/operator/deployment)。

---

## 群管基础操作

### 禁言、解禁与全体禁言

群管理员或机器人主人可在群内使用以下命令（`@成员` 指真实艾特消息片段，`QQ号` 为纯数字）：

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `#禁言 @成员 [时长]` / `#禁言 <QQ号> [时长]` | 禁言指定成员，默认 300 秒，上限 2147483647 秒 | `#禁言 @张三 10分钟`、`#禁言 123456 2小时` |
| `#解禁 @成员` / `#解禁 <QQ号>` | 解除指定成员禁言 | `#解禁 @张三`、`#解禁 123456` |
| `#全体禁言` / `#全体解禁` | 开启或关闭全员禁言（亦支持 `#全员禁言` / `#全员解禁`） | `#全体禁言` |
| `#禁言列表` / `#获取禁言列表` / `#查看禁言列表` | 合并转发当前被禁言成员及剩余时间 | `#禁言列表` |
| `#解除全部禁言` | 批量解除当前所有被禁言成员 | `#解除全部禁言` |
| `#我要自闭[时长]` / `#我要禅定[时长]` | 群友自助禁言（`#` 可选，时长紧跟其后无空格），默认 5 分钟 | `#我要自闭30分钟`、`#我要禅定1小时` |

- **时长单位**：支持 `毫秒`、`秒`/`S`/`SECOND`、`分`/`分钟`/`M`/`MIN`/`MINUTE`、`时`/`小时`/`H`/`HOUR`、`天`/`日`/`D`/`DAY`、`周`/`W`/`WEEK`、`月`/`MONTH`、`年`/`Y`/`YEAR`，数字支持阿拉伯数字与中文数字（如 `十`、`两`）。
- **主人私聊群管**：机器人主人可在私聊中对指定群执行禁言、解禁、全体禁言或踢出操作，详见 [主人配置指南](/yunzai/docs/operator/configuration)。

### 踢出、管理与群精华

- `#踢 @成员` / `#踢<QQ号>`：将成员移出群聊（QQ 号前无空格，如 `#踢123456`）。
- `#踢黑 @成员` / `#踢黑<QQ号>`：移出群聊并加入跨群群管黑名单（QQ 号前无空格，如 `#踢黑123456`）。
- `#加精` / `#设精` / `#移精`：需**引用**目标消息发送（`#` 可选），设置或取消群精华。
- `#设置管理 @成员` / `#设置管理 <QQ号>`、`#取消管理 @成员` / `#取消管理 <QQ号>`：设置或取消群管理员（仅主人可用）。
- `#群管加白` / `#群管删白`、`#群管加黑` / `#群管删黑`：后接 `@成员` 或 `<QQ号>`，维护群管白名单（白名单成员受保护，不可被普通管理禁言或踢出）与黑名单。
- `#开启白名单自动解禁` / `#关闭白名单自动解禁`：开关白名单成员被禁言后的自动解禁。

### 群名称、群名片与资料卡点赞

- `#改群名 <新名称>` / `#改群昵称 <新名称>`：修改当前群名称。
- `#改群名片 [@成员] <新名片>`：仅主人可用。群内不 `@` 成员时修改机器人自身名片。
- **资料卡点赞**：群友可发送 `#赞我`、`#点赞`、`#资料卡点赞`、`#超我`（`#` 可选）为自己点赞，或在群内发送 `#赞他 @成员`、`#超TA @成员` 为他人点赞；`#全部赞我` 仅在群聊生效。

## 入群验证、投票与活跃度清理

### 入群验证

新成员入群后需在规定时间内发送算术题答案，超时或答错将被移出群聊：

- `#开启验证` / `#关闭验证`：开关本群入群验证。
- `#绕过验证 @成员` / `#绕过验证<QQ号>`：跳过指定成员当前的验证（QQ 号前无空格，如 `#绕过验证123456`）。
- `#重新验证 @成员` / `#重新验证<QQ号>`：为指定成员重新发起验证（QQ 号前无空格，如 `#重新验证123456`）。
- `#重新验证从未发言的人`：对群内所有从未发言的普通成员批量发起验证。
- 验证模式与超时时间由机器人主人配置，详见 [主人配置指南](/yunzai/docs/operator/configuration)。

### 群投票

- `#发起投票禁言 @成员` / `#发起投票禁言 <QQ号>`、`#发起投票踢人 @成员` / `#发起投票踢人 <QQ号>`：发起针对目标成员的禁言或踢人投票（不可对群主、机器人或受保护成员发起）。
- `#支持投票 @成员` / `#支持投票 <QQ号>`、`#反对投票 @成员` / `#反对投票 <QQ号>`：参与当前投票；若开启管理员一票决定权，管理员投票将直接结束并生效或取消。
- **投票设置（需权限）**：`#启用投票禁言`、`#禁用投票禁言`、`#启用投票踢人`、`#禁用投票踢人`、`#投票设置<超时时间|最低票数|禁言时间><数值>`（如 `#投票设置禁言时间8600`）。

### 活跃度查询、清理与成员导出

- `#查看从未发言过的人` / `#查看从未发言过的人第N页`：分页查看入群后从未发言的成员（每页 30 人，`第N页` 紧跟其后无空格，如 `#查看从未发言过的人第2页`）。
- `#查看<时长>没发言的人` / `#查看<时长>没发言的人第N页`：按未发言时长筛选（无空格，如 `#查看30天没发言的人第2页`）；`#获取<时长>没发言的人` 需群管权限。
- `#不活跃排行榜[数量]` / `#潜水排行榜[数量]` / `#最近入群记录[数量]`：查看活跃度或入群排行（数字紧跟其后无空格，默认前 10 名，如 `#不活跃排行榜20`）。
- `#清理从未发言过的人[第N页]` / `#清理<时长>没发言的人[第N页]`：预览待清理名单后，需在 **120 秒内**发送 `#确认清理` 开始执行，或发送 `#取消清理` 放弃。
- `#群成员`：在群内发送可导出当前群成员列表为 CSV 文件（私聊导出需附带群号 `#群成员 <群号>`）。
- `#群清理退群 <用户QQ> [群号]`：清理已退群用户的群通知回退档案。

## 违禁词、屏蔽词与头衔管理

### 群违禁词

支持文本、正则与图片（需在命令后附带原图）规则，每群上限 256 条：

- `#违禁词帮助`：查看命令格式说明。
- `#新增[模糊|精确|正则1|正则2][踢撤|禁撤|踢黑|踢|禁|撤]违禁词 <内容>`：新增规则，默认 `精确` 匹配、`禁`（禁言）。
  - 示例：`#新增模糊撤违禁词 广告`、`#新增正则2禁违禁词 /^示例$/i`
- `#查看违禁词 <内容>` / `#删除违禁词 <内容>`：查看或删除指定规则（图片规则可附带原图）。
- `#违禁词列表` / `#违禁词列表原始`：合并转发当前群所有违禁词。
- `#设置违禁词禁言时间<秒数>`：设置触发禁言处罚时的默认秒数（默认 300 秒）。

### 屏蔽词

- `#屏蔽词列表`：查看本群及全局屏蔽词。
- `#屏蔽本群 <词1,词2>` / `#解除屏蔽本群 <词1,词2>`（亦支持 `删除`/`取消`/`不屏蔽`）：添加或移除本群屏蔽词（多个词用中/英文逗号分隔，单次最多 32 个）。
- 全局屏蔽词与全局开关由机器人主人管理。

### 群头衔与头衔屏蔽词

- `#申请头衔 <头衔>` / `#我要头衔 <头衔>`：自助申请或清空自己的群头衔（受头衔屏蔽词检查）。
- `#设置头衔 [@成员] <头衔>`：为自己设置头衔；`@` 他人修改仅主人可用。
- `#增加头衔屏蔽词 <词1,词2>` / `#减少头衔屏蔽词 <词1,词2>` / `#查看头衔屏蔽词`：管理本群头衔屏蔽词。
- `#切换头衔屏蔽词匹配`：在 `精确` 与 `模糊` 匹配模式间切换。

## 定时禁言、加群通知与退群拉黑

- **定时群禁言**：
  - `#定时禁言 <HH:MM|6段cron>` / `#定时解禁 <HH:MM|6段cron>`：设置定时任务，如 `#定时禁言 23:00`、`#定时解禁 07:00`。
  - `#取消定时禁言` / `#取消定时解禁`：取消对应定时任务。
  - `#绑定旧定时禁言` / `#绑定旧定时解禁`：绑定迁移前的旧定时任务。
  - `#定时禁言任务`：查看本群当前定时任务状态。
- **加群申请通知**：群内发送 `#开启加群通知` / `#关闭加群通知`，开启后有新加群申请时将在群内发送通知。
- **退群拉黑**：`#退群拉黑查询 <QQ号>`、`#退群拉黑解除 <QQ号>`（需在已启用退群黑名单的群内由群主/授权会话操作）。

## 消息词条（自定义回复）

消息词条支持按群隔离或全局共享，同一关键词可添加多条回复（触发时随机抽取或按序号指定）。

### 作用域与权限

- **本群词条**：在群内发送 `#添加`、`#删除`、`#消息`、`#词条` 直接操作当前群；在私聊中使用时，将自动关联你最近一次发言的群（若配置禁止私聊管理则仅限群内操作）。
- **添加/删除权限**：取决于群配置 `addLimit`——`0` 为群友可用，`1` 为仅群主或群管理员可用，`2` 为仅机器人主人可用。
- **全局词条**：`#全局添加`、`#全局删除`、`#全局消息列表`，仅机器人主人可增删。

### 常用命令与添加步骤

1. 发送 `#添加 <关键词>`（主人可用 `#全局添加 <关键词>`）。
2. 连续发送要回复的内容（支持文本、图片、QQ 表情，单次会话上限 1000 个片段，超时时间 120 秒）。
3. 发送 `#结束添加` 完成保存。

- **查询与列表**：
  - `#消息` / `#词条` / `#消息列表 [页码]`：查看本群词条列表（每页 100 条）。
  - `#消息 <关键词>`：搜索包含指定关键词的词条。
  - `#全局消息列表 [页码]` / `#全局表情`：查看全局词条。
  - `#合并词条列表 [页码]`：合并查看当前群与全局词条（同名键优先保留本群词条）。
- **删除**：`#删除 <关键词>`；若同一关键词有多条回复，可在末尾加序号删除指定条目（如 `#删除 欢迎2`）。
- **触发**：在群内直接发送 `关键词` 即可触发回复，发送 `关键词+序号` 可触发指定条目。

## 群公告与全局公告

### QQ 群公告

- `#查群公告`：群成员均可使用，查看本群最近最多 20 条群公告。
- `#发群公告 <内容>`：在当前群发布 QQ 群公告（需群管权限）。
- `#删群公告<序号>`：删除指定序号的群公告（序号紧跟其后无空格，需先通过 `#查群公告` 确认序号）。

### 机器人全局公告

- `#公告`：查看当前最新全局公告。
- `#历史公告 [编号]`：查看上一条或指定编号的历史公告。
- `#全部历史公告 [页码]`：合并转发历史公告（每页 10 条）。
- `#公告帮助`：查看公告命令说明。
- 机器人主人可通过 `#发布公告`、`#推送公告` 等命令管理与推送全局公告，详见 [主人配置指南](/yunzai/docs/operator/configuration)。

## 入群审核、通知与公开查询

### 群内加群申请审核

- `#查看加群申请`：查看当前群待处理的加群申请（最多展示 50 条）。
- `#同意加群申请<QQ号>` / `#拒绝加群申请<QQ号>`：审核指定用户的加群申请（QQ 号前无空格）。
- `#同意全部加群申请` / `#拒绝全部加群申请`：批量审核当前可核验的加群申请。
- **引用审核**：直接引用机器人发送的加群通知消息，回复 `同意` 或 `拒绝`。
- 机器人主人私聊审核好友申请、群邀请及回复好友消息的命令，详见 [主人配置指南](/yunzai/docs/operator/configuration)。

### 通知设置与米游社公告查询

- `#通知设置`：查看当前机器人及本群的各类事件通知开关与撤回缓存时间（主人修改开关与作用域请参见 [主人配置指南](/yunzai/docs/operator/configuration)）。
- **米游社公开查询**：支持查询原神、星铁、绝区零、崩坏3 等游戏的公告、资讯与活动（如 `#原神公告`、`#星铁资讯`、`#绝区零活动`、`#米游社 <关键词>`）。
