# 账号绑定与管理

Lotus-Yunzai 将本地米游社凭据、设备信息、三游角色、国际服 Cookie 与云游戏 Token 按**档案编号（1–255）**独立存储。账号管理类指令默认档案为 **1**，省略编号时即操作档案 1（例如 `#扫码登录` 等同于 `#扫码登录1`）；游戏查询类指令则使用各自游戏对应的默认档案（未切换时均为档案 1）。

> **安全与会话提示**
> - 扫码登录、设备绑定/解绑、本人角色目录与档案切换支持在群聊与当前连接机器人的好友私聊使用。群内相关回复默认 **120 秒**后撤回（若功能本身设置了更短撤回时间则保留更短值）；待处理会话按当前连接与会话隔离，不可跨群或跨私聊/群聊消费设备绑定窗口或取消原会话扫码。
> - 在群聊发送设备资料时，机器人会尝试立即撤回你的原始消息；若机器人没有群管理权限导致撤回失败，会提示你自行撤回。
> - 国际服 Cookie、云游戏 Token 绑定、旧版 `#删除ck` 以及面板文件导入/导出仍**仅限好友私聊**，切勿在群聊明文发送 Cookie、Token 等敏感凭据。
> - 档案中的“已登录（`loggedIn`）”仅表示本地同时存有 Cookie 与 SToken 字段，不代表凭据此刻一定通过米游社实时认证；遇到接口失效时请使用 `#刷新cookie` 或重新 `#扫码登录`。

## 三种绑定方式的区别

Lotus-Yunzai 提供三种不同层级的账号/UID 接入方式，按需选用即可：

| 方式 | 典型指令 | 是否需要登录 | 可用功能与边界 |
| :--- | :--- | :--- | :--- |
| **米游社扫码登录** | `#扫码登录` | 是（群聊或好友私聊） | 本地保存 Cookie、SToken、设备与三游角色；支持签到、兑换码、战绩、抽卡、本人面板等 |
| **档案内选角** | `#角色列表`、`#切换角色2` | 切换时须已登录（查看可读已迁入/历史目录） | 查看当前档案已同步或迁入的三游角色目录；在已登录档案中选择该游戏的当前角色，不改变登录信息或默认档案 |
| **公开 UID 临时查询** | `#查询公开UID <UID>` | 否 | 匿名读取对应游戏公开展柜的角色数量（每次须提供完整 UID），不保存 UID 列表、默认绑定或账号授权 |

一份档案保存一份通行证登录。只有该通行证实际返回的官服、B 服等角色才会按游戏保存在同一档案中；切换角色只改变该档案、该游戏的选中角色。

## 米游社扫码登录与多档案

系统已停用账号密码登录，所有米游社账号须在群聊或当前连接机器人的好友私聊中扫码绑定。

### 扫码登录步骤

1. 在群聊或好友私聊发送 `#扫码登录`（默认档案 1）或 `#扫码登录2`（指定档案 2，支持 `1`–`255`；也支持 `#二维码登录`、`#米游社登录`）。
2. 收到登录二维码后，使用米游社 App 扫码并在手机端确认登录。
3. 登录信息保存后，系统会自动同步该账号下的原神、崩坏：星穹铁道、绝区零角色。若提示角色暂未同步，可发送 `#同步角色`（或 `#同步角色2`）手动重试。

### 取消登录等待

- 二维码生成后等待确认期间，若需放弃当前会话的登录，在**同一群聊或私聊会话**发送 `#取消扫码登录`（或 `#取消扫码登录2`）即可中止；跨群或跨会话无法取消原会话扫码。
- 若手机端已点击确认且后台正在写入档案，则无法中途取消，需等待保存完成。

## 档案查看、刷新与清除

| 功能 | 常用指令 | 说明与范围差异 |
| :--- | :--- | :--- |
| **查看档案列表** | `#登录列表`（别名 `#账号列表`） | 列出当前 QQ 已创建的档案及状态；建议在私聊查看，避免在群内暴露资料 |
| **查看档案详情** | `#配置` / `#配置2` | 展示通行证、Cookie/SToken 保存状态（敏感字段已脱敏）、设备状态、三游角色、签到与国际服/云游戏配置 |
| **同步三游角色** | `#同步角色` / `#同步角色2` | 重新拉取该档案下的原神、星铁、绝区零角色目录 |
| **刷新登录凭据** | `#刷新cookie` / `#刷新cookie2` | **不带档号刷新当前 QQ 名下全部档案**；带档号仅刷新指定档案。受 `checkin.refresh` 策略控制（默认 `inherit`，未设置 `deny` 等限制策略时普通用户可用） |
| **清除登录凭据** | `#清除登录` / `#清除登录2` | **不带档号仅清除档案 1**。仅清空 Cookie/SToken 等登录凭据，保留设备、角色与签到设置 |

> **刷新与清除的范围差异**
> - `#刷新cookie` 省略档号时会遍历你名下所有档案；`#清除登录` 省略档号时**只清除档案 1**，不会误清档案 2 及后续档案。
> - `#清除登录` 不会删除整份档案：已绑定的设备信息、角色列表和签到开关都会保留，方便之后重新扫码恢复。
> - 旧版 `#删除ck`（及 `#星铁删除ck`、`#绝区零删除ck`，仅限好友私聊）会按游戏查找已登录且有选定角色的档案；若多个档案同时符合，系统会拒绝猜测并提示改用 `#清除登录<档号>` 指定。

## 本人角色目录与默认档案切换

登录多个档案或单个账号拥有多个区服角色时，可通过本人角色目录查看与切换当前角色，并按游戏分别设定默认档案。本人角色目录查看、选角与档案切换支持群聊和好友私聊（均只操作发令者本人的档案；群聊回复默认 120 秒后撤回）。

### 查看档案与切换角色

前缀 `#` 对应原神、`*` 对应星铁、`%` 对应绝区零，也可使用 `#原神`、`#星铁`、`#绝区零`。

| 指令示例 | 作用 |
| :--- | :--- |
| `#当前档案` | 只读查看三游各自的默认档案（带 `*` / `%` 或 `#星铁` / `#绝区零` 前缀可只看对应游戏） |
| `#档案列表` | 只读查看各游戏默认档案及本人已登录档案列表 |
| `#切换档案2` / `*切换档案2` / `%切换档案2` | 显式切换对应游戏的默认档案（`#切换档案N` 默认仅切换原神，不能一次切三游）；要求目标档案已登录且存在该游戏角色，保留该档案原有的选中角色 |
| `#角色列表` / `#UID` | 查看当前档案（按对应游戏默认档案路由）的三游角色目录，不混入其他档案或公开 UID；已有迁入历史目录时即使登录失效仍可查看 |
| `*角色列表` / `%角色列表` | 查看星铁或绝区零当前默认档案的角色目录 |
| `#角色列表 档案2` | 临时查看档案 2 的角色目录，不改变默认档案 |
| `#切换角色2` / `#UID2` | 选中当前档案内的第 2 个原神角色（序号 1–99）；**须当前档案已登录**，且不会修改游戏默认档案 |
| `*切换角色2 档案2` | 选中档案 2 内的第 2 个星铁角色，须已登录且不改变默认档案 |
| `#切换角色 100000042 档案2` | 按 8–10 位游戏 UID 选中档案 2 已同步的本人角色，须已登录，不能用于登记外部角色 |

角色序号仅在当前展示的档案内有效。查看目录只读取历史/已同步目录；切换角色会校验登录态与角色归属，且只更改所选档案对应游戏的选中角色，不改变默认档案；需要换号时请使用对应游戏的 `切换档案` 指令（账号管理类指令省略档号时仍固定为档案 1）。

### 公开 UID 临时查询

发送 `#查询公开UID 100000042`、`*查询公开UID 100000042` 或 `%查询公开UID 100000042`（支持 `#原神` / `#星铁` / `#绝区零` 前缀），可匿名查看 Enka（原神、绝区零）或 Mihomo（星铁）公开展柜的角色数量。每次都须填写 8–10 位完整游戏 UID（不以 0 开头），查询不保存绑定，也不会影响本人的档案与角色。

> **已停用的旧 UID 入口说明**
> - 原有的独立 UID 绑定/设置/切换（如 `#绑定原神UID`、`#设置原神UID`、`#切换原神UID` 等）、游戏内签名验证口令，以及公开 UID 登记/列表/切换/删除入口（`#登记公开UID`、`#公开UID列表`、`#切换公开UID`、`#删除公开UID`、`#删除UID`）均**已停用**。
> - 发送旧指令会直接提示新用法，不再生成签名口令或写入旧引用；本地已有旧归档仍予保留（不会删除），但不再参与默认账号选择、旧面板恢复或面板导出授权。需要本人账号功能或面板导出时，请先扫码登录（显式 UID 导出须属于当前游戏默认登录档案，面板文件导入/导出仍限好友私聊）。

## 设备绑定与自动设备

米游社社区签到与部分防风控接口需要匹配的 `device_id` 与 13 位十六进制设备指纹 `fp`。Lotus-Yunzai 支持手动绑定真机设备，也会在未手绑时按需生成自动设备。

### 手动绑定设备

前提：目标档案已完成 `#扫码登录`；使用私聊时需先加机器人好友。

1. 在群聊或好友私聊发送 `#绑定设备`（或 `#绑定设备2`，支持 `#原神` / `#星铁` / `#绝区零` / `%` 前缀；查看简短提示可用 `#绝区零绑定设备帮助`）。
2. 系统进入 **120 秒（两分钟）**等待窗口，并尝试在当前会话发送设备信息提取工具 `copy_device_info_1.2.apk`（若当前连接不支持传文件或本地文件不可用，会提供下载链接；你也可以直接发送手头已有的设备资料）。
3. 在两分钟内于**同一会话**发送设备资料（也可以在第一步直接发送 `#绑定设备2 <设备JSON或字段>` 一次性提交）：
   - **方式 A：发送真机配对参数**：在同一条消息中提供同一真实设备的 `device_id`（8–128 位字母、数字、`_` 或 `-`）和 13 位十六进制 `device_fp`（`fp`），可选附带 `device_name`、`device_model`、`android_version`。
   - **方式 B：发送工具 APK 导出的完整安卓 JSON**：当 JSON 中不含 `device_id` / `device_fp`，但包含完整安卓设备参数（`deviceName`、`deviceModel`、`deviceFingerprint`、`deviceProduct`、`deviceBoard` 及有效的 `oaid`）时，系统会自动补齐设备标识并向官方申请 `fp`。
4. 群聊中发送设备资料时，机器人会尝试立即撤回你的原始消息；若机器人没有群管理权限导致撤回失败，会提示你自行撤回。在好友私聊绑定成功后，也请**在 QQ 中自行撤回刚才发送的设备资料消息**。

字段文本模板（仅作格式占位，请替换为真实设备提取结果，勿填写失效或虚构的 `fp`）：

```text
device_id=<真实设备ID>
device_fp=<13位十六进制设备指纹>
```

> **提交注意事项**
> - 不要提交含 `ext_fields`、`seed_id` 的指纹申请请求体，也不要提交非成功的响应报文。
> - 若导出的 JSON 中 `oaid` 为空或以 `error_` 开头，请重新运行 APK 获取有效参数后再提交。
> - 等待期间在当前会话发送 `#取消绑定设备`（或 `#取消绑定设备2`，或直接发送 `取消`）可立即退出等待。

### 自动设备、覆盖关系与解绑

- **查看设备状态**：发送 `#设备信息` / `#设备信息2`（或 `#配置` / `#配置2`），可查看当前是“已绑定”（手绑真机）、“自动设备”（含是否已取得 `FP`）还是“未绑定”。
- **覆盖优先级**：
  - **手工绑定会覆盖自动设备**：一旦通过 `#绑定设备` 保存真机设备，该档案将转为使用手工绑定设备。
  - **后台生成不覆盖已手绑/完整旧设备**：后台自动设备维护任务只会为未手动绑定且缺少有效设备标识（或仅含早期占位标识）的已登录档案生成安卓参数并定期申请指纹；不会改动任何已手动绑定的设备或完整的旧设备资料。
- **解绑设备**：在本人群聊会话或好友私聊发送 `#解绑设备` 或 `#解绑设备2`，仅将设备重置为未绑定状态，**保留当前档案的登录凭据与角色设置**。

## 国际服 Cookie 与云游戏 Token

国际服（HoYoLAB）与国服云游戏（云原神、云绝区零）的凭据**必须绑定在已本地登录（`loggedIn`）的档案上**。米游社扫码登录**不会**自动获得或替代国际服 Cookie 与云游戏 Token。

### 国际服（HoYoLAB）配置

1. **绑定国际服 Cookie（仅限好友私聊）**：发送 `#绑定国际服Cookie <Cookie>` 或 `#绑定国际服Cookie2 <Cookie>`（也支持“海外服”写法）。系统会先联网核验 Cookie 有效性及其 HoYoLAB 账号身份（不要求与国服米游社通行证同号），核验通过后写入指定档案。
2. **开启或关闭签到**：发送 `#开启国际服签到` / `#关闭国际服签到`（可加档号如 `#开启国际服签到2`，支持 `启用`、`禁用` 及省略“签到”二字）。
3. **设置语言**：发送 `#设置国际服语言 <语言代码>` 或 `#设置国际服语言2 <语言代码>`（例如 `zh-cn`、`en-us`；语言代码须为 1–32 位字母、`_` 或 `-`，不允许数字）。

### 云原神与云绝区零配置

请从正常登录的官方云游戏客户端或网页会话获取自身真实凭据，切勿在群聊或终端发送凭据，也不要自行构造或猜测 Token。

| 操作 | 云原神指令 | 云绝区零指令 | 说明 |
| :--- | :--- | :--- | :--- |
| **绑定凭据（好友私聊）** | `#绑定云原神Token <Token>` | `#绑定云绝区零Token <Token>` | 档号写在 `Token` 后（如 `#绑定云原神Token2 <Token>`）；保存前会试读钱包验证有效性 |
| **开启/关闭签到** | `#开启云原神签到` / `#关闭云原神签到` | `#开启云绝区零签到` / `#关闭云绝区零签到` | 支持 `启用`/`禁用` 与档号后缀（如 `#开启云原神签到2`） |
| **查询云原神钱包** | `#云原神查询` / `#云原神查询2` | — | 查看对应档案的米云币、免费时长与总时长 |
