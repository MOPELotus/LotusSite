# 媒体与图片功能

本模块提供主流音视频与图文平台的链接自动解析、关键词搜视频、视频下载、网页摘要、Wiki 查询、米游社官号视频查询以及动态/投稿订阅功能。

## 1. 能力范围与边界（预览 ≠ 下载）

发送受支持的链接或分享卡片时，机器人会自动识别并尝试解析。不同平台的能力边界如下：

| 平台 | 自动预览 | 视频下载 / 播放 | 说明与前置条件 |
| --- | --- | --- | --- |
| **B 站（视频 / 直播 / 动态）** | 视频、直播间、动态 | 支持视频下载 | 需主人开启下载且当前会话有下载权限 |
| **B 站（番剧）** | 番剧信息卡（`ep` / `ss`） | 支持按配置自动或指令下载 | 需主人开启番剧解析与下载 |
| **抖音** | 视频、图文、直播间 | 支持视频下载（不含直播） | 需主人开启下载且当前会话有下载权限 |
| **AcFun** | 公开视频信息卡 | 需发送 `#播放 链接` | 需已初始化媒体环境（FFmpeg）及播放权限 |
| **快手** | 公开短视频信息卡 | 自动发送公开视频（≤100MB） | 需当前会话有下载权限 |
| **皮皮虾** | 公开作品信息卡 | 自动发送可下载视频（≤100MB） | 需当前会话有下载权限；附带热门评论 |
| **微视 / 最右** | 公开分享信息卡 / 图集 | 需发送 `#播放 链接` | 需当前会话有预览/播放权限 |
| **米游社帖子** | 合并转发图文内容 | 自动发送附带视频（≤100MB） | 需当前会话支持合并转发与媒体投递 |
| **即刻** | 动态文字与原图（≤18张） | **不支持** | 视频帖仅显示封面与时长 |
| **小红书** | 公开笔记信息卡 | **不支持** | 需当前会话有预览权限 |
| **西瓜视频** | 公开视频信息卡 | **不支持** | 需当前会话有预览权限 |
| **微信视频号** | 公开视频号信息卡 | **不支持** | 需当前会话有预览权限 |
| **小黑盒** | PC 游戏名称预览卡 | **不支持** | 仅支持 PC 游戏分享，需当前会话有预览权限 |
| **QQ 小世界** | 仅返回停服提示与原链接 | **不支持** | — |

> 注：私聊场景下，多数平台需机器人主人开启对应的私聊解析开关才会触发自动解析。

## 2. 平台解析与下载用法

### 2.1 B 站（Bilibili）

#### 自动解析与搜索
- **链接/号段直出**：在群聊或私聊中直接发送 `bilibili.com`、`b23.tv`、`bili2233.cn` 链接，或 `BV号` / `av号`，机器人将发送信息卡片、公开评论（如有）并尝试下载视频。
- **番剧解析**：发送 `bilibili.com/bangumi/play/ep...` 或 `ss...` 链接，自动返回番剧信息卡；若主人开启了番剧自动下载，还会自动发送对应剧集。
- **普通搜索**：
  - `#搜视频 关键词` 或 `#点B站视频 关键词`（或 `#点哔站视频 关键词`）
  - `#点B站视频` 为图库分页模式，每页最多 42 条。
  - 搜索后 2 分钟内，普通搜索发送 `#看1`（`#看` 与数字相邻无空格），图库模式发送 `#看B站视频 1`（或 `#看哔站视频 1`）选择对应条目；图库模式支持 `#B站上一页`、`#B站下一页` 翻页。
- **关键词直看**：`#看视频 关键词`，直接搜索并解析第一条结果。

#### 主动下载
- `#B站下载 <链接/BV号/av号>` 或 `#B站下视频 <链接/BV号/av号>`（指令与参数间需有空格）
- 番剧主动下载：`#播放 <番剧链接>` 或 `#B站下载 <番剧链接>`
- 示例：`#B站下载 BV1xx411c7mD`

#### 引用回复操作
回复（引用）B 站分享卡片或机器人发出的 B 站解析结果，可发送以下指令：
- `#解析` / `解析` / `#解`：重新触发预览解析
- `#下载封面` / `封面下载` / `获取封面` / `封面`：获取视频封面原图
- `#简介` / `简介`：查看视频完整简介（最多 3000 字）
- `#下载视频` / `视频下载` / `获取视频`：下载并发送该视频
- `#获取图片` / `下载图片` / `图片`：提取动态中的原图（最多 9 张）
- `#展开` / `展开 [序号]`：展开评论区第 `序号` 条评论的子评论（默认第 1 条）
- `#评论 正文` / `评论 正文`：向该视频或动态发表评论（**仅机器人主人可用**，正文 1–1000 字）

### 2.2 抖音

- **自动解析**：直接发送抖音分享链接或口令，机器人会发送作品信息卡片（或图文长图），并在有权限且开启下载时发送视频；若为直播间链接，仅发送房间预览。
- **主动下载**：`#抖音下载 <分享链接>` 或 `#抖音下视频 <分享链接>`（指令与链接间需有空格）
  - 仅执行下载并发送视频，不额外发送信息卡片。

### 2.3 AcFun

- **自动解析**：直接发送 AcFun 视频链接，机器人返回视频信息卡片及播放提示。
- **播放/下载视频**：`#播放 <AcFun链接>`
  - 需机器人主人已初始化媒体环境（FFmpeg），且合成后的 MP4 不超过发送上限（支持大文件投递时上限 100MB，否则 16MB）。

### 2.4 快手、皮皮虾、微视与最右

- **快手**：发送 `v.kuaishou.com/...`、`www.kuaishou.com/short-video/...` 或 `*.m.chenzhongtech.com/fw/photo/...` 链接，自动返回信息卡片；若有下载权限且为公开视频，自动下载发送。
- **皮皮虾**：发送 `h5.pipix.com/item/...` 或 `h5.pipix.com/s/...` 链接，自动返回信息卡片；若作品允许下载且有下载权限，自动下载发送，并在支持合并转发时附带热门评论。
- **微视 / 最右**：直接发送分享链接可预览信息卡或图集；若分享包含公开视频，可发送 `#播放 <原文链接>`（中间需有空格）请求下载发送视频。

### 2.5 米游社、即刻与其他公开预览

- **米游社帖子**：发送 `miyoushe.com/<分区>/article/<id>` 链接，自动以合并转发形式发送图文内容与原图链接；若帖子包含视频，将在投递完成后自动发送视频。
- **米游社官号视频查询**：发送 `#最新视频`（不带参数），查询已配置游戏的最新官号视频动态（群聊中会自动过滤本群已屏蔽的游戏）。
- **即刻**：发送 `m.okjike.com/originalPosts/<24位ID>` 链接，自动发送动态正文卡片与原图（最多 18 张）；不支持视频下载。
- **小红书 / 西瓜视频 / 微信视频号 / 小黑盒**：直接发送对应平台分享链接，仅返回公开预览信息卡片与原链接，不支持下载。

## 3. 网页总结与 Wiki 查询

### 3.1 网页总结
- **命令**：`#总结一下 <网页链接>`（`#` 与 `＃` 均可）
- **说明**：支持部分公开文章页、arXiv 论文及 V2EX 帖子。若机器人已配置摘要模型，将通过合并转发发送阅读时长估算与内容摘要；未配置或未启用摘要时，返回原文摘录卡片。

### 3.2 Minecraft Wiki 查询
- **命令**：`#mcwiki <条目名称>`
- **示例**：`#mcwiki 红石比较器`
- **说明**：查询中文 Minecraft Wiki 条目，通过合并转发返回条目链接、渲染预览图及修订版本与许可说明。

## 4. 动态与投稿订阅

发送 `#媒体帮助` 或 `/媒体帮助` 可查看订阅指令帮助卡片。

### 4.1 通用动态订阅（B 站 / 微博）

指令支持 `#` 或 `/` 前缀。平台别名支持：`B站`、`哔哩哔哩`、`哔哩`、`bilibili`、`bili`、`微博`、`weibo`。

- **添加订阅（仅机器人主人）**：
  - 语法：`#添加<平台>推送 [类别...] <纯数字UID>`（`添加` 可替换为 `订阅` / `add`）
  - 可选类别：`视频`、`图文`、`文章`、`转发`、`直播`（微博不支持 `直播`）。不填类别则订阅全部动态。
  - 示例：`#添加B站推送 视频 直播 123456`、`#订阅微博推送 1234567890`
- **取消订阅（仅机器人主人）**：
  - 语法：`#删除<平台>推送 [类别...] <纯数字UID>`（`删除` 可替换为 `取消` / `del`）
  - 指定类别时仅取消对应类别，不指定类别则移除该 UID 的全部订阅。
- **查看订阅列表**：
  - `#B站订阅列表` / `#微博订阅列表`：查看当前群聊或私聊的订阅（所有用户可用）。
  - `#B站全部订阅列表` / `#微博全部订阅列表`：查看当前机器人全部会话的订阅（**仅机器人主人**）。
- **手动执行检查（仅机器人主人）**：
  - `#执行B站任务` / `#执行微博任务`（需已连接 Redis）。
- **查询公开资料**：
  - `#B站UP主UID:123456`、`#B站UP主昵称:关键词`
  - `#微博博主UID:123456`、`#微博博主昵称:关键词`

### 4.2 B 站投稿订阅（群聊专用）

仅在群聊中可用，支持实时推送 UP 主新投稿视频。

- **权限**：**本群群主、群管理员或机器人主人**可添加/取消；所有群友可查看列表。
- **添加订阅**：`#订阅B站视频推送 [UID]`（`订阅` 可替换为 `添加` / `开启`）
  - 可省略 UID，直接**引用**一条可识别的 B 站视频消息后发送 `#订阅B站视频推送`。
- **取消订阅**：`#取消B站视频推送 [UID]`（`取消` 可替换为 `删除` / `关闭`）
- **查看列表**：`#B站视频推送列表`
- **迁移旧订阅**：`#迁移B站视频推送 [机器人QQ]`（不填机器人 QQ 时仅限机器人主人执行）

## 5. 权限与环境提示

- **普通群友**：可使用链接预览、搜视频、查看本群订阅列表、查询 UP 主/博主资料、`#最新视频`、`#mcwiki`、`#总结一下` 等功能。
- **群管理员 / 群主**：除普通群友权限外，可管理本群的 **B 站投稿订阅**。
- **机器人主人**：负责全局开关、下载权限、Cookie/账号登录、动态订阅管理及媒体环境初始化（如 `#初始化环境`）。相关配置与部署说明请参见 [主人配置指南](/yunzai/docs/operator/configuration) 与 [部署指南](/yunzai/docs/operator/deployment)。
