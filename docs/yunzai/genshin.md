# 原神

当前机器人安装了 Yunzai Genshin、miao-plugin、Lotus-ReFactor、Mora、逍遥相关扩展及其他原神工具。不同插件有相同关键词时，实际响应由插件优先级和群设置决定；可先发 `#帮助`、`#喵喵帮助` 或 `#摩拉帮助` 看本群菜单。

## 角色、材料与账号数据

| 示例指令 | 用途 |
| --- | --- |
| `#角色`、`#角色卡片`、`#探险` | 查询绑定 UID 的角色资料。 |
| `#刻晴`、`#刻晴攻略`、`#刻晴突破` | 查看角色详情、攻略或突破素材；把“刻晴”换成目标角色名。 |
| `#武器`、`#五星`、`#四星`、`#角色背包` | 查询武器或角色背包。 |
| `#深渊`、`#深渊十二层` | 查看深渊记录。 |
| `#体力`、`#原石`、`#原石统计` | 查询体力与原石札记。 |
| `#今日素材` | 查询当前日期可刷素材。 |
| `#公告`、`#资讯`、`#活动` | 查询原神公告与活动资讯。 |

角色面板、角色练度和伤害分析可查看[荷花插件（Refactor）文档](/projects/lotus-refactor/)或发送 `#喵喵帮助`、`#面板帮助`。常见面板操作是公开角色展柜后使用 `#更新面板`；查询结果依赖面板服务和角色展柜可见性。

## 祈愿记录与模拟抽卡

| 指令 | 用途 |
| --- | --- |
| `#角色记录`、`#武器记录`、`#常驻记录` | 查询已导入祈愿记录。 |
| `#角色统计`、`#武器统计`、`#常驻统计` | 按卡池统计抽卡结果。 |
| `#记录帮助` | 查看导入记录流程。 |
| `#十连`、`#十连武器`、`#十连常驻` | 插件提供的模拟祈愿，不会消耗真实游戏资源。 |

有些记录导入方式需要游戏内抽卡记录链接。抽卡链接具有账户关联性，不要发送到群里或转给他人；本机器人不提供私聊，如导入流程要求提交敏感信息，请联系荷花。

## 绑定说明

- 查询功能可能需要绑定游戏 UID：先发送 `#绑定uid`，再按提示提交 UID。
- 需要米游社授权的功能可发送 `#体力帮助` 或 `#Cookie帮助` 查看当前流程。`#我的ck`、`#绑定Cookie` 和 `#删除Cookie` 等命令涉及账号会话；本机器人不提供私聊，不要在群内提交 Cookie 或其他凭据，需要处理时联系荷花。
- 不要将 Cookie 原文、登录二维码、短信验证码、密码或包含凭据的完整 URL 粘贴到群聊。
- 授权后可用 `#uid` 确认绑定的是哪个游戏 UID；不再使用时按帮助提示解除授权。

## 攻略与扩展

Mora 插件可查询攻略、一图流、复刻表和深渊参考，例如 `#钟离攻略`、`#角色复刻表`、`#虚空深渊队伍`。发送 `#摩拉帮助` 查看当前支持的游戏和功能。

成就查漏可发送 `#成就帮助`。支持的录入方式、扫描限制和数据重置流程以插件返回的菜单为准；重置前确认是否会删除自己的记录。
