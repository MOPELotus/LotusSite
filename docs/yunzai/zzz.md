# 绝区零

绝区零常规指令使用 `%` 前缀。发送 `%帮助` 查看 ZZZ-Plugin 的菜单；角色面板、资源和展柜功能以该菜单为准。

## 绑定设备由荷花插件接管

`#绑定设备` 和 `#绝区零绑定设备` 由荷花插件（Lotus-ReFactor）处理，会覆盖 ZZZ-Plugin 的同名设备绑定入口。绑定信息按荷花插件的 profile 保存，并用于对应账号的绝区零查询；这两个命令使用 `#` 是荷花插件的专用指令，不改变绝区零常规指令使用 `%` 的规则。

绑定流程可能要求提交设备 JSON。本机器人不提供私聊，**不要把设备 JSON 发到群里**；需要绑定时请联系荷花。

## 查询与面板

- 可先发送 `%帮助` 查看角色面板、资源、展柜和插件设置命令。
- `%更新展柜面板` 使用公开展柜数据服务查询面板；结果可能受服务可用性和展柜状态影响。
- Mora 支持部分绝区零角色攻略、卡池详情等内容，可发送 `#摩拉帮助` 查看范围。
- 遇到图片资源缺失或角色未更新时，先查看 `%帮助` 的资源维护项；删除缓存类操作会触发重新下载。

## 设备与账号安全

设备信息可能包含手机型号或标识符。本站不需要也不收集这些参数；不要在群里公开发送。

遇到验证码或账号风险提示时应暂停请求，按米哈游官方渠道确认账号状态。任何“百分百绕过验证”的说法都不可信。
