# 指令写法与权限

## 基本格式

先发送纯指令，再按机器人提示补充角色名、页数或选项。不同插件的参数格式不同，使用对应的帮助命令确认空格、别名和可选项。

## 游戏指令前缀

| 指令类别 | 前缀 | 示例 |
| --- | --- | --- |
| 原神或通用指令 | `#` | `#帮助`、`#体力`、`#原石统计` |
| 星穹铁道 | `*` | `*体力` |
| 绝区零 | `%` | `%帮助`、`%更新面板` |

- 荷花插件的设备绑定命令由插件接管，使用 `#绑定设备` 或 `#绝区零绑定设备`；它会覆盖 ZZZ-Plugin 的同名绑定入口。由于机器人不提供私聊，遇到要求发送 Cookie、stoken、验证码或设备 JSON 的流程时，不要在群里提交，请联系荷花。
- 消息平台可能会把井号、@提及、图片和换行解析成特殊消息；遇到不识别时可复制纯文本重新发送。

## 群聊使用范围

- 本机器人只在群聊中提供交互，不提供私聊功能。
- 群管理功能要求你有群管理员身份，且机器人自身也必须有相应权限。
- 机器人没有回复时，先确认它在线、所在群未禁用机器人、指令前缀正确，再检查是否需要 @机器人。

## 权限标记

| 标记 | 含义 |
| --- | --- |
| 用户 | 普通用户可用；仍可能受群配置或频率限制。 |
| 群管理员 | 你需要是群管理员，机器人也需要对应群权限。 |
| 机器人主人 | 仅机器人所有者或授权维护者可用。 |
| 高风险维护命令 | 可能改动账号、群聊或服务器状态。只由可信主人按明确说明操作。 |

具体权限以实际机器人提示为准。不同协议端对禁言、踢人、头像和群公告等能力支持不同。

## 账号与凭据安全

部分游戏数据查询需要先绑定游戏 UID 或账号会话。只使用官方游戏/社区页面及机器人明确提供的绑定方式；不要向陌生人、群聊或本站发送 Cookie、stoken、短信验证码、二维码、OTP 密钥、密码或设备指纹。机器人不提供私聊；如果某项功能要求提交这些信息，请联系荷花，不要在群内继续。

本站不会代收账号信息，也不会提供“绕过验证”承诺。平台可能要求重新登录或触发安全验证；如有疑问，停止操作并联系荷花。

## 常用系统功能

以下是 Yunzai/TRSS-Yunzai 部署中常见指令，部分只对管理员开放：

| 指令 | 用途 | 权限 |
| --- | --- | --- |
| `#帮助` | 显示机器人和插件帮助菜单。 | 用户 |
| `#状态` | 查看机器人状态；群聊中可能返回群数据。 | 用户/按配置 |
| `#版本` | 查看框架或插件版本。 | 按插件配置 |
| `#更新日志` | 查看版本更新记录。 | 按插件配置 |
| `#禁言 @用户 时长` / `#解禁 @用户` | 群内管理。 | 群管理员，且机器人需有权限 |
| `#踢 @用户` | 移出群聊。 | 群管理员，且机器人需有权限 |

更新、重启、拉黑、查看日志和管理账号的命令通常只对主人开放；不要尝试执行陌生人发送的维护指令。
