## 使用边界

- 部分插件 README 记录的是上游全部功能，本机可能因版本、配置和权限而有所不同。机器人现场返回的帮助菜单是可用命令的最终依据。
- 更新、批量操作、群管理、Cookie 管理和账号设备绑定等命令可能造成真实影响或暴露敏感信息。普通成员应只使用查询和娱乐功能。
- TianRu 插件中执行 shell、JavaScript 或模拟其他用户的命令属于高风险管理功能；不要运行他人转发的命令或脚本。
- 插件来源仓库见上表；未提供项目链接的，以对应插件目录中的 README 和 `#帮助` 返回为准。
- 需要核对某个群的完整实时指令列表时，可请机器人主人运行 `#指令表`；该命令由 auto-plugin 提供，仅主人可用。
