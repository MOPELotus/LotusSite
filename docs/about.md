# 关于本站

本站介绍 MOPELotus 维护的项目，并为正在使用机器人服务的用户提供指令说明。

项目源码及问题反馈请通过各项目页中的 GitHub 链接访问。机器人指令是否可用还取决于当前账号权限、群聊设置、上游服务状态和插件版本。

## 文档更新

项目 README 与 `docs/` 由 GitHub Actions 定时同步。Yunzai 使用说明根据本机当前安装的插件和功能整理；插件行为变化后，本站说明也会随之更新。

本站不会要求用户在群聊中发送 Cookie、口令、验证码、设备凭据或其他账号密钥。机器人不提供私聊；需要登录或绑定账号但流程要求提交敏感信息时，请联系荷花。
