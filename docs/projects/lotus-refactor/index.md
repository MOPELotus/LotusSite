# Lotus-ReFactor

Lotus-ReFactor 是 Lotus-Plugin 的重构版，面向 Yunzai，包含角色与游戏资料、账户辅助和日常管理等功能。部分能力会影响其他插件的指令行为；使用前请阅读插件说明和权限要求。

## 查看功能与命令

该插件的命令和配置说明会随版本调整。请从[插件文档目录](/synced/lotus-refactor/docs/README)进入，再按主题查阅安装、初始化、权限、签到、B 站、游戏数据查询、账号和验证码等指南。命令是否出现在你的机器人菜单中，取决于当前安装版本和账号权限。

## 重要提醒

- Cookie、stoken、mid、验证码平台密钥和 OTP 密钥属于敏感凭据。本机器人不提供私聊，不要在群聊或公共 issue 中提交；需要登录或绑定时请联系荷花。
- 涉及远程执行、账户登录或群管理的功能仅限可信管理员，并应先确认指令影响范围。
- 插件许可为源码可见的专有许可。请查看同步的[许可文件](/synced/lotus-refactor/LICENSE.txt)及仓库说明。
