# MusicHud-TuneWeave

MusicHud-TuneWeave 是一个基于 MusicHud 的 Minecraft 音乐项目，通过独立的 TuneWeave 服务访问多个音乐平台。客户端支持 Fabric 和 NeoForge；Paper、Velocity 与 BungeeCord 服务器可以安装配套插件，共享队列和公共播放状态。

## 功能

- 在音乐界面中搜索歌曲、歌单、专辑和歌手，管理播放队列。
- 显示封面、逐字歌词和 HUD 播放状态，并跳转到音乐来源。
- 支持多人同步听歌、投票切歌、队列与空闲播放源。
- 连接独立运行的 TuneWeave 服务；音乐平台账号凭证留在客户端侧。

## 开始使用

1. 安装与 Minecraft 版本和加载器匹配的模组及依赖。
2. 进入世界后按 **M** 打开界面，按需配置或下载本机 TuneWeave 服务。
3. 选择平台、搜索歌曲并加入队列。多人服务器需在对应 Paper 或代理层安装同发行版本的服务端插件。

版本范围、Fabric/NeoForge 依赖、多人部署拓扑和故障排查会随 Minecraft 版本变化，请查看[同步的项目 README](/synced/musichud-tuneweave/README)和[部署说明](/synced/musichud-tuneweave/docs/deployment)。
